# Ace 후방 접근 구간 시범

새 교사는 Ace 별도조건16경기 중10경기에서후방피해를냈지만전체받은피해가크다. 전체경로를그대로모방하지않고피격후후방공격으로연결되는구간만보조지도에사용하는안을검토한다.

20경기27971상태를14.96초에수집했고모든경기체력·승패·시간·실제후방피해가이전실행과정확일치했다. 각후방피해발생에대해직전최대8초를표시하되가장최근피격틱까지를제외했다. 관측/실행행동/체력감소/선택마스크를모두보존한다. 마스크는사후라벨선택이며모델입력에는미래정보를주지않는다. 미래에선택된상태만배우므로실제도달분포차이가남는다는한계가있다.

탐색초기조건2개양좌석4경기는학습,확인초기조건8개양좌석16경기는fit-validation으로분리했다. 이검증조건은이미교사평가에쓰였으므로미사용최종시험이아니다. 전체2391상태가선택됐다. 파일해시·마스크재계산·피격틱제외·초기조건분리검증은data_audit.json에있다.

다음은기존시범부모를정확복원하고기존일반행동보존자료를유지한작은모방비교다. 기존Circler시범도보존하여단일상대개선이기존행동을지우는지검사한다. 아직학습가중치는변경하지않았다. 기존Weave전체혼합/DAgger실패를반복하는것과달리실제후방피해접근구간을분리하지만성공을보장하지않는다. 상대별대결없이모방손실감소만으로채택하지않는다.
