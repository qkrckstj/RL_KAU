# 2026-10-06 진행 내용과 GitHub 보관 범위

이번 업데이트는 **다중 상대 리그의 최종 평가가 진행 중인 시점**을 보관한다.
신경망 학습의 실패 진단부터 CEM 정책 확보, 여러 정책을 상대하는 자동 학습까지 코드·모델·결과를 연결했다.
현재 목표는 다른 참가자 정책과의 대회 성능이며, 아직 실제 참가자 모델을 평가하지는 않았다.

평균 성적뿐 아니라 취약 상대의 성적을 반영하고, 교체되지 못한 후보도 다음 학습 상대에 남겼다.

## 결과를 읽을 때의 구분

- **200전 전승은 이전 Ace 상대 시험**이다. 다른 참가자 모두를 이긴 결과가 아니다.
- **75.58%는 13종 상대 개발 평가**다. 아직 완료되지 않은 16종 상대 최종 시험 승률로 표시하지 않는다.
- 추가 학습 3회는 같은 학습 부모와 상대 집합을 공유한다. 처음부터 독립적으로 좋은 방법을 세 번 발견했다는 뜻은 아니다.
- 이번 리그 학습에서 제외한 상대는 Lead, Circler, 과거 DDQN seed 0이다. 실제 참가자 제출물은 아직 없다.
- 최종 시험은 공통 40개 초기조건×양 좌석×16상대=정책당 1,280경기다. 전체 경기 수를 독립 초기조건 수로 세지 않는다.
- 회피형 Evader에는 무승부가 지속돼 별도 추격 진단을 예약했다. 모든 연속 상태를 경험하거나 모든 정책을 이길 수 있다고 가정하지 않는다.

## 이번에 보관하는 것

추가된 실험 코드와 테스트, 학습 계획·판단 기록, 저장된 정책 가중치와 제어 계수,
완료된 경기 기록, CEM 탐색 분포와 난수 상태, 소스 사본과 해시를 보관한다.
실패하거나 개선하지 못한 실험도 결과를 보존한다. 신경망 모델의 중간 가중치도 포함한다.

현재 실행 중인 최종 평가의 부분 경기 결과와 계속 바뀌는 진행 로그는 이번 스냅샷에서 제외한다.
평가 완료 후 결과를 추가로 보관한다. 시험 band **40000000은 이미 열었으므로 소진된 시험**으로 취급한다.
대기 작업의 과거 PID를 다른 컴퓨터에서 그대로 사용하지 않는다.

약 1.3GB의 새 **과거 신경망 재생 버퍼**는 로컬에 보존한다. 모델 불러오기·추론·대결에는 필요하지 않지만,
해당 신경망 learner의 경험을 그대로 이어 학습하려면 버퍼를 별도로 옮겨야 한다.
현재 CEM 리그는 이 버퍼를 쓰지 않으며, 완료된 탐색 상태와 정책은 이 업데이트에 포함한다.
환경 폴더, 패키지 캐시와 인증 파일은 저장소에 포함하지 않는다.

정확한 보관 파일과 로컬 유지 파일의 경로·크기·SHA256은

## 실행 예시

설치 후 `aircombat-rl` 폴더에서 Python 3.12 환경을 사용한다.

```powershell
# 최종 시험 전에 선택한 정책을 Ace와 비행시켜 보기
python -m tools.watch templates/project_04_fair --design runs/league_20261006/followup_pool/chosen --seed 32000500

# 사전 선택 정책과 원래 CEM의 새 개발 대결
python -m tools.league_duel --a runs/league_20261006/followup_pool/chosen --b experiments/plan_a/cem_policy --out runs/my_comparison --band 33020000 --n 40

# 실제 다른 사람의 정책을 받았을 때
python -m tools.league_duel --a runs/league_20261006/followup_pool/chosen --b path/to/other_policy --out runs/new_opponent --band 33021000 --n 40
```

현재 자동 작업은 16상대 최종 평가→미세조정 정책끼리 대결→도주형 상대 진단→저장·실행 검사·보고서 작성 순서다.
평가 실패나 새로운 개선 가능성이 나오면 후속 분석을 이어간다. GitHub 업로드가 학습 목표의 완료를 뜻하지 않는다.
