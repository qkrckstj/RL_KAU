# 취약 상대 반복 노출 비교

## 집중 방식의 두 반복 완료

집중 방식의 두 반복 승률은 58.98%, 63.28%로 평균 61.13%다. 오른쪽 weave 상대는 각각 5승 2무 1패와 4승 1무 3패였지만 이탈 상대는 두 번 모두 0승 8패, evader는 8무승부였다. 두 모델 모두 기존 선택 모델을 대체하지 않는다. `three_branches_partial_raw_analysis.json`에서 원시 기록을 검증했다. 마지막 기준 반복을 마친 후 방식 간 최종 비교를 한다.

보존 중인 시작 모델의 같은 weave 상대 결과도 1승 2무 5패였다. 따라서 이 개발 패널에서 집중 학습의 weave 개선은 성능이 낮아진 기준 분기와의 비교에만 해당하는 것은 아니다. 다만 초기 조건 4개와 행동 난수 두 개를 재사용한 개발 결과이므로 새 조건에 대한 일반화는 아직 검증하지 않았다. 전체 성능 저하와 이탈 상대 전패도 남아 있다.

## 첫 반복 완료

첫 집중 분기 `focal35/s6300`도 1,048,576단계를 완료했다. 전체 승률은 58.98%로 기준 분기의 64.84%, 시작 모델의 68.75%보다 낮아 기존 모델을 유지했다. 오른쪽 weave 상대는 기준 분기 1승 3무 4패에서 집중 분기 5승 2무 1패로 개선됐지만, 이탈 상대는 두 방식 모두 0승 8패, evader는 8무승부였다. 일부 상대의 개선을 전체 성능 개선으로 해석하지 않는다.

실제 설정·원시 대결·점수·보존 검사는 `first_pair_partial_raw_analysis.json`, 완료된 에피소드 노출 횟수는 `first_pair_exposure_audit.json`에 기록했다. 현재 두 번째 집중 분기가 이어지고 있다. 두 반복 결과가 모이기 전에는 이 전술별 차이의 재현성을 확정하지 않는다.

첫 기준 분기 `archive/s6300`는 1,048,576단계를 완료했다. 이번 88M 개발 조건에서 공통 시작 모델 승률은 68.75%, 기준 분기 후속 모델은 64.84%였으며 기존 모델을 유지했다. 이탈 상대 0승 8패, 오른쪽 weave 상대 1승 3무 4패, evader 상대 8무승부였다. `first_archive_partial_raw_analysis.json`에서 실제 설정·원시 대결·점수·보존 여부를 검사했다. 현재 첫 `focal35` 분기가 이어지고 있다. 87M의 71.09%와 직접 전후 비교하지 않는다.

이전 rollout·GAE 비교는 총 6,291,456단계를 완료했고 종료 코드 0, 원시 결과 검증을 통과했다. 평균 승률은 기본 설정 56.25%, 긴 rollout 67.19%, 긴 GAE 62.50%였다. 공통 시작 정책은 같은 개발 조건에서 71.09%였다. 여섯 후보 모두 동결된 종합 평가 기준에서 이전 선택 정책을 갱신하지 못했으므로 기존 모델을 보존한다. 결과는 `runs/league_credit_horizon_train_20261007/raw_credit_analysis.json`에 있다.

완료된 첫 다섯 분기는 각각 757~787개 에피소드를 끝냈지만 `temporal_extend_right`를 만난 횟수는 9~10회였다. 해당 상대의 계획상 에피소드 선택 비중은 약 1.17%였다. 이것만으로 실패 원인이 증명되는 것은 아니지만, 학습량 전체를 늘리기보다 취약 상대 반복 노출을 직접 비교할 근거가 된다. 기록은 `five_branch_exposure_audit.json`에 있다. 완료된 에피소드 수와 선택 분포는 학습 단계 비율이 아니며, 아직 진행 중인 에피소드와 길이 차이가 영향을 준다.

두 방식은 같은 기존 단일 시점 모델의 정책·가치 함수·Adam 상태에서 출발한다. PPO rollout은 둘 다 512단계, GAE는 0.99로 고정한다. 기존 104개 상대를 모두 보존한다.

| 방식 | 에피소드 선택 일정의 구성 |
|---|---|
| archive | 기존 70% 균등 + 15% 상대 그룹 균등 + 15% 전체 약점 분포 |
| focal35 | 55% 균등 + 10% 상대 그룹 균등 + 35% 지정 취약 상대 분포 |

지정 상대는 `temporal_extend_right`, `temporal_weave_right`, `evader`다. 35% 안에서 기존 동결 약점 가중치로 배분하며, 각각을 35%씩 배정하는 것이 아니다. 모든 상대를 섞어 한 번씩 만나는 선택과 가중 추출을 번갈아 수행한다. 정책 관측에 상대 ID를 넣지 않으며 공식 물리·초기 조건·행동·승패를 바꾸지 않는다.

실행기: `tools/league_focal_curriculum_train.py`. 두 방식 각각 32,768단계 실제 학습·저장·복원 점검 후, 방식별 두 반복 × 1,048,576단계로 총 4,194,304단계를 비교한다. 학습 초기 조건은 282M/283M, 개발 조건은 88M이다. 원시 분석기는 `tools/league_focal_curriculum_analysis.py`다.

관심 결과는 세 지정 상대의 승패 개선과 전체·상대 그룹 성능 저하 여부다. 취약 상대만 좋아진 후보를 대회용 우수 정책으로 선언하지 않는다. 효과가 있으면 더 학습할지, 새 조건·상대에서 재평가할지 판단한다. GitHub 업로드는 하지 않는다.
