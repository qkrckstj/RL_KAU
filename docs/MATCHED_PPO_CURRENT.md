후속 `league_sampled_control_extend_20261007`은 기본 방식의 최신 1M 체크포인트 두 경로에 각각 1,048,576단계를 추가한다. 경로별 pilot 이후 누적 학습량은 2,097,152단계다. 두 후보의 actor/critic/optimizer를 정확히 불러오되 새 학습 RNG5700/5701과 초기조건272M/273M를 사용한다. 중단 직전 JSBSim 상태나 과거 RNG 궤적을 복원하는 실행은 아니다. 기존 개발 최선 모델을 각각 유지하므로 새 후보가 나빠지면 이전 모델을 선택한다. 원래 모델을 포함한 이전 산출물은 모두 보존한다.

첫 학습 RNG5300의 세 전략이 모두 완료됐다(추가 3,145,728단계). 개발 패널 승률은 control 179/256(69.92%), balanced 165/256(64.45%), lower_prior 128/256(50.00%)다. lower_prior는 편향 변경 직후 기준이 20/256(7.81%)로 급락했고 학습으로 일부 회복했다. 이를 원래 모델 대비 개선이라고 해석하면 안 된다. 신경망 텐서는 같아도 고정 logit 편향이 바뀌면 시작 정책의 행동 분포가 달라진다. 급격한 편향 변경이 현재 모델과 잘 맞지 않는다는 관찰이며, 원인을 확정하거나 완화 전략 전체를 배제하는 근거는 아니다. 두 번째 RNG5301을 lower_prior → balanced → control 순서로 자동 실행 중이다. 원시 기록의 해시를 포함한 `first_rng_analysis.json`을 남겼다. 두 RNG가 끝나기 전에는 최종 전략 선택이나 연장을 하지 않는다.

두 번째 본 학습 balanced/RNG5300도 1,048,576단계를 완료했다. 동일 개발 패널 승률은 169/256(66.02%) → 165/256(64.45%)로 내려갔다. 더 낮은 복제의 하위 사분위 점수는 28.13% → 29.69%로 조금 올랐으나 종합 순위는 기준보다 낮아 기준 모델을 유지했다. 새 체크포인트는 비교용으로 보존했다. 학습 415.26초, 평가 43.76초다. 근거는 실행 폴더 `balanced_s5300_analysis.json`이다. 세 번째 전략 lower_prior/RNG5300이 자동으로 시작됐다. 한 RNG만으로 balanced 전략을 최종 탈락시키거나 학습 예산을 변경하지 않는다.

첫 본 학습 control/RNG5300이 1,048,576단계를 완료했다. 동일 개발 패널의 상대 균등 승률은 169/256(66.02%) → 179/256(69.92%), 코드 그룹 균등 승률은 72.69% → 73.06%다. 행동 난수 복제 중 더 낮은 하위 사분위 점수는 28.13% → 26.56%로 내려갔다. 전체 승률 증가가 모든 취약 상대 개선을 뜻하지 않는다. 학습 429.50초, 체크포인트 평가 75.30초로 두 작업 합계에서 평가 비중은 14.92%였다. 시작 전 기준 평가와 작업자 생성 시간은 이 비율에서 제외됐다. 근거는 실행 폴더 `control_s5300_analysis.json`과 동결된 원시 평가 기록이다. 두 번째 전략 balanced/RNG5300이 자동으로 시작됐다. 나머지 전략과 두 번째 RNG가 완료되기 전에는 전략 우열·연장·승격을 결정하지 않는다.
