# 지연 보상의 할인율 비교

## 근거와 한계

시범 다양화와 기존 행동 보존 강도 변경은 넓은 상대군에서 뚜렷한 개선을 만들지 못했다. 고정 가중치의greedy 진단도25상대에서mixed72.0%,DAgger70.0%,보존 후보72.25%,CEM73.5%로 끝났다. 새 실행440경기63.67초,기존960경기재사용,전체 준비/검사 포함82.87초다. 작은7상대 점검의 우위를 일반화하지 않는다.

기존 학습은 물리 한 단계0.05초에gamma0.999를 적용한다. 보상의 할인 반감기는 약34.64초다. 60초 뒤의 동일한 보상은약0.301배,120초 뒤는0.091배다. 후방을 잡는 데 시간이 걸리면 빠른 정면 교전보다 낮게 평가될 가능성이 있다. 이것이 현재 문제의 원인이라고 확정하지 않는다.

gamma0.9997에서는 반감기가약115.51초,60초 뒤0.698배,120초 뒤0.487배다. 이 실험은 긴 행동 순서 끝의 결과를 더 중시하는 학습 목표를 비교한다. GAE lambda나 rollout 길이를 함께 바꾸지 않는다.

## 고정하는 것

- 실제FairFight 물리·무장·종료·체력 소수점4자리 승패 기준.
- 기존CEM/PPO 및 모든 실패 후보 아카이브.
- 이미 추적 시범을 배운retention9400/9501의actor·critic·Adam 상태. 각 부모에서 대조/실험을 같은 상태로 복원한다.
- 기존48상대와 확률,50%사분면 시작/50%원래 시작,보상 계수,prior6,learning rate0.0001,GAE lambda0.99,rollout640,32환경,8작업자.
- 두 실행 난수9700/9701. 각 대조/실험 쌍은 새433M/434M 훈련 초기조건 흐름을 공유한다. 두 부모는 공통 조상과 시범 자료를 공유하므로 처음부터 독립 학습한 정책은 아니다.

## 바꾸는 것과 검사

대조gamma0.999,실험gamma0.9997 한 요인만 바꾼다. PPO 객체·rollout buffer·환경의 잠재함수 보상에 같은gamma를 적용한다. 잠재함수 보상은 할인율과 일치시켜야 하므로 이 연동 변경은 의도적이다. 다른 보상 계수를 바꾸지 않는다. 모든 환경의gamma를 읽어 확인하고 저장 후PPO와buffer의gamma 복원도 검사한다. 두 갈래의 초기 가중치/Adam 일치,기존 설정에서gamma 외 변경 없음도 검사한다.

먼저2×10,240단계 및8경기의 통합 검사. 통과하면2부모×2할인율×655,360단계=총2,621,440단계를 실행한다. 평가24상대×4기존초기조건×양 좌석×2행동 난수×4후보=1,536경기다. 조건은 재사용 개발 조건115M이며 미사용 최종 시험이 아니다.

승률만 오르거나 훈련 중 위치 보상만 좋아진 경우 성공으로 보지 않는다. 두 반복의 승률·실제 후방 사격·받은 피해·정면 피해를 함께 확인한다. 개선이 반복되면 새 조건/상대 확인과 영상을 추가하고,그렇지 않으면 무조건 분량을 늘리지 않는다. GitHub 자동 업로드는 하지 않는다.

## 난수 보완

첫 통합 검사 `league_tail_discount_smoke_20261012`는20,480단계/8경기에서gamma·가중치·Adam 저장복원을 통과했다. 하지만 학습 전 검증용 `PPO.load`가 전역 난수를 체크포인트의seed로 재설정하는 것을 별도 검사에서 확인했다(요청9799→로드 뒤9400). 따라서 이 실행은 성능 판단이나 올바른 학습 난수 검사의 근거로 사용하지 않는다.

동결된 첫 실행을 수정하지 않고 `league_tail_discount_train_v2.py`에서 모든 검증용 로드를 마친 뒤 `model.set_random_seed(seed)`를 다시 호출한다. 실제PyTorch 난수와모델seed가요청seed와 같은지 검사하고 `actual_learner_seed`에 기록한다. `league_tail_discount_smoke_v2_20261012`의 새로운908M 통합 검사를 통과해야 본 실행한다. 본 실행은 `league_tail_discount_experiment_v2`다.

같은 검증 패턴을 쓴 이전 연속학습은 환경/초기조건 흐름이 실행seed별로 달랐어도 신경망 학습 전역 난수가 파일명의seed와 같다고 단정할 수 없다. 원시 승패와저장된 정책은 유지되며,그 결과를 완전히 독립된 신경망 난수 반복이라고 재해석하지 않는다. 이전 시범학습의 명시적seed설정 검사는 별도이며 이미 정정된seed_note를 따른다. 이 보완으로 이전 승패 결과가 바뀐다고 주장하지 않는다.

## 한 차례 연장

`league_tail_discount_extend`는 각 대조/실험 갈래가 방금 저장한 자신의actor/critic/Adam/gamma를 그대로 이어받는다. 갈래 사이 가중치는 이제 서로 다른 것이 정상이며,각각 부모final digest와초기digest 일치를 검사한다. 다른 하이퍼파라미터를 바꾸지 않는다.435M/436M의 새 훈련조건과9800/9801의 새 학습난수로 각655,360단계,합계2,621,440단계를 추가한다. 처음부터 다시 시작하거나 중단 궤적을 정확 복원하는 실행은 아니다.

먼저909M의20,480단계/8경기 통합 검사 후 본 실행한다. 연장 후 동일24상대/1,536경기를 평가하고,첫분량·학습전부모·현재대조군을 함께 비교한다. 연장해도 개선 추세가 없으면 같은 설정의 추가연장을 자동 반복하지 않는다. 현재 시범 후보와CEM은 계속 보존한다.
