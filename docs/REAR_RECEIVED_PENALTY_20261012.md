# 피격 벌점 계수 단독 비교

직전 상대 단계화는 승률 효과가 반복마다 달랐고 Circler 외 후방 전이는 거의 없었다. 48개의 기존 league_tail 계열 계획에서 받은 피해 계수는 모두 .5였다. 현재 후보의 평균 피격 .581/.583 중 정면 기하에서 받은 피해가 .570/.577이었다. 이 관찰은 원인을 입증하지 않지만 피격 비용을 강화하는 비교의 근거다.

## 단일 변경

기존 `tail_coefficients.received`만 .5→1.0으로 바꾼다. 새로운 후방·정렬·상대 커리큘럼은 추가하지 않는다. 기존 PPO 부모 actor/critic/Adam을 복원하고 동일 학습 난수10100/10101 및 소비한 초기조건 대역441M/442M, 각655,360단계로 비교한다. 총 새 PPO 1,310,720단계이며 대조군의 같은 양 학습은 기존 기록을 재사용한다.

원래 상대48종/분포, quarter50%, 위치 .01, 실제 후방 피해 .5, 잠재·유지·가한 피해 계수, prior6, gamma .999 및 PPO 설정 보존. CPU8작업자32환경, 메모리 보호 및 해시 검증 유지. 물리·무장·종료와 round4 종료체력 승패는 바꾸지 않는다. 기존 CEM/PPO와 동결 기록을 덮어쓰지 않는다.

보상 계수 변경은 목적을 바꾸므로 단순 회피가 강화될 위험이 있다. 승률·가한 피해·받은 피해·정면 피해·후방 사격권 체류·실제 후방 피해를 함께 평가한다. 두 반복이 일관되게 좋아질 때 추가 반복과 미사용 조건으로 확인하며, 회피만 늘거나 승률을 잃으면 채택하지 않는다.

## 검증과 비용

동일 행동을 적용한 양 좌석 전체 경기에서 관측·체력·승패·종료·후방 피해가 같고 추가 보상이 피격량의 -.5배인지 검사했다. 기존 보상은 float32 공개 관측 체력, 종료 정보는 float64를 사용한다. 첫 검사에서 이 표현 차이를 확인하여 기존 float32 정의로 정확 비교하도록 검사를 수정했으며 환경 코드는 바꾸지 않았다. 두 검사 통과(9.36초).

20,480단계 통합 점검은 별도 출력에 수행하며 본 실행은 점검 모델이 아닌 원래 부모에서 시작한다. 평가는 두 후보×행동 난수2×24상대×2초기조건×양좌석 = 새384경기다. 이전 정렬 실험에서 검증된 동일 대조384경기를 해시와 체력·승패·시간 대조 후 재사용한다. 총768비교 셀이나 새768경기를 실행한 것은 아니다. 모두 개발 조건이며 미사용 최종 시험이 아니다.

실행: `tools/league_rear_received_experiment.py`, `tools/league_rear_received_train.py`. 완료검토: `tools/league_rear_received_review.py`. 실행 중인 폴더 재사용이나 중복 프로세스 시작 금지. GitHub 자동 업로드 없음.
