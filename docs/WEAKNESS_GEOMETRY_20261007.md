# 반복 패배 교전 진단

취약 상대 비중 비교는 4,194,304단계를 완료했고 종료 코드 0, 원시 결과 검증을 통과했다. 기존 분포의 두 반복 평균 승률은 65.23%, 집중 분포는 61.13%, 공통 시작 모델은 같은 개발 조건에서 68.75%였다. 모든 후보는 기존 선택 모델을 대체하지 못했다.

집중 분포는 오른쪽 weave 상대에 두 반복 각각 5승·4승(8판)을 얻어 시작 모델의 1승보다 높았다. 그러나 이탈 상대는 계속 전패했고 evader는 계속 무승부였다. 한 상대에 대한 개선만으로 전체 우수 정책으로 승격하지 않는다. 원시 비교는 `runs/league_focal_curriculum_train_20261007/raw_focal_analysis.json`에 있다.

다음 실행 `runs/league_weakness_geometry_20261007`은 세 취약 상대를 대상으로 한 소규모 교전 진단이다. 시작 모델의 행동 난수 두 개, 집중 학습 두 모델의 행동 난수 각각 두 개, 보존한 CEM, Ace·lead·pursuit·circler·고정 좌회전·고정 우회전을 비교한다. 총 13개 행동 정책 × 3상대 × 4초기 조건·양 진영 = 312판이다. 조건 89M은 새 조건이며, 모든 정책은 결과를 보기 전에 고정했다.

피격 시점, 체력 변화, 1초 간격의 거리·양쪽 기수 오차·속도·자기 행동을 기록한다. 추가 기록은 행동 결정 후에 수집하고 정책 입력으로 전달하지 않는다. 단순 봇을 비교하는 이유는 동일 공식 행동 공간에서 다른 전술이 이 상대를 이길 수 있는지 확인하기 위해서다. 이 세 상대 결과를 전체 대회 성능으로 일반화하지 않는다.

`tools/league_weakness_geometry.py`의 기록 계측을 켠 대결과 기존 대결을 72판 실행해 모든 공식 에피소드·승패 집계의 일치를 확인한 후 본 진단을 시작했다. 작업자는 8개이며 학습과 동시에 실행하지 않았다. 진단 결과로 다음 학습 전략을 결정한다. GitHub 업로드는 하지 않는다.
