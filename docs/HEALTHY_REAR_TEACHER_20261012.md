# 종료 체력을 반영한 후방 교사 탐색

이전 주기는 전략·논문 게시로 진행을 남겼다. 현재 최신 학습의 종료 파일과 PID 비활성을 확인한 뒤 별도 탐색을 시작했다. 시작 전 커밋 여유 약 10.63GiB.

## 한 요인 비교

이전 교사 탐색과 같은 17개 파라미터, 앵커, 난수 10201, 4세대×16후보×3상대×2초기조건×양 좌석(768경기), 작업자 8개를 유지한다. 원래 점수 .5승률 + 후방피해 + .5최약상대후방피해 − .25받은피해에서 후방피해 항만 `실제 후방피해 × 종료 내 체력`으로 바꾼다. 최약상대 항에도 같은 정의를 쓴다. 이는 피격 이전에 낸 피해나 사격 순간의 체력을 직접 측정하는 항이 아니다. 경기 종료 승패·물리·기존 정책은 바꾸지 않는다. PPO 업데이트는 0이다.

동일 입력에서 내 체력이 많이 남으면 점수가 커지는 검사를 통과했다. 첫 세대의 모든 경기를 과거 첫 세대와 정확히 비교하고 전체 768경기의 점수·체력판정·물리단계를 재계산한다. 세대 사이 커밋 여유 2.8GiB를 검사한다.

## 후속 개발 평가

선정된 후보를 기존 24상대×2초기조건×양 좌석=96경기에 평가한다. 기존 전문가 3개의 동일 조건 288경기를 재사용한다. 승률·실제 후방 피해·피격·정면 피해와 Circler 외 성능을 분리한다. 모두 이미 사용한 개발 조건이며 독립 최종 시험이 아니다. 좋아진 경우에만 독립 탐색 반복 및 추가 확인으로 진행한다.

실행: `python -m tools.league_tail_healthy_teacher_search --out runs/league_tail_healthy_teacher_search_20261012`; 완료 후 `python -m tools.league_tail_healthy_teacher_confirm`. 기존 출력 폴더에는 재실행하지 않는다. 새 실행은 기존 모델을 승격하거나 덮어쓰지 않는다.

## 완료 결과 — 채택하지 않음

탐색 세션13962와 평가21483 모두 종료 코드0. 첫 세대192경기는 과거 탐색과 정확히 같았고 전체768경기의 점수·승패·단계를 재검사했다.

- 탐색: 1,344,466 시뮬레이션 단계, 768경기, 111.17초. PPO 업데이트 0.
- 평가: 신규96경기 + 기존288경기 재사용, 20.43초.
- 탐색+평가 측정 구간 합계: 131.60초. 두 실행 사이 분석·코드 작성·시작 전 검사는 이 합계에 포함하지 않으므로 전체 벽시계 시간으로 부르지 않는다.

새 후보 19/96승(19.79%), 기존 후방 교사20/96승(20.83%). 받은 피해는 .71910→.67604로 감소했지만 평균 후방 피해도 .03720→.01306으로 감소했다. 후방 피해 경기는9→5, 무피격 후방 공격 승리는0→1이었다. 기존 PPO68/96승, CEM70/96승을 대체하지 못한다. 무피격 한 사례만으로 개선으로 판단하지 않는다.

탐색64후보 중 후방 피해가 있었던 것은 중복 포함4개, 고유3개뿐이었다. 그중 최소 평균 피격은 기존 후방 교사의 .708125였으며 더 건강한 후방 교사를 새로 확보하지 못했다. 선두는 훈련 후방 피해0인 후보였다. 체력 가중 후방 점수를 장기 연장하지 않는다.
