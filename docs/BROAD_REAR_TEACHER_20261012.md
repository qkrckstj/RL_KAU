## 현재 실행의 목적

직전 종료체력 가중 탐색은 완료·평가했으나 채택하지 않았다. 새 탐색은 원래 점수 `.5승률 + 평균후방피해 + .5최약상대후방피해 - .25피격`을 유지하고 훈련 상대를 3종에서 6종으로 넓힌다. 새 점수를 더 조정하는 실험이 아니다.

- 기존 Ace/Lead/Pursuit에 Circler, 실제 CEM6800(`extend_cem_s6800_g3_c9`), 학습 정책 `episode_mix_sampled_4900` 추가.
- 같은 17개 파라미터, 원래 앵커·난수10201·초기조건441000010/11·양 좌석·4세대×16후보.
- 상대 수 증가로 768→1,536경기다. 후보/세대 예산은 같지만 계산량은 같지 않다. 순수한 동일 계산량 알고리즘 우월성 시험으로 해석하지 않는다.
- 원래3종 상대에 대해 점수 함수가 정확히 일치하는 검사 통과. 첫 세대의 공통 상대192경기는 과거 기록과 정확한 재생 일치를 검사한다.
- 작업자8개. 시작 메모리 여유10.66GiB. 세대 사이 여유2.8GiB 검사. 기존 FairFight 물리·종료·round4체력승패 및 모델은 보존한다. PPO 단계0.

## 후속 평가와 결정

새 선두 후보를 동일 개발24상대×2초기조건×양 좌석=96경기에 평가한다. 기존 PPO/CEM/후방교사 288경기 재사용. 개발 조건은 이미 사용했으므로 미사용 시험으로 부르지 않는다. 승률·피격·후방피해·정면피해·후방체류와 상대별/비Circler를 함께 확인한다. 사격권 시간과 실제 피해를 혼동하지 않는다.

후방 교사의 폭넓은 공격/피격 균형이 개선되는 후보가 확인되면 독립 탐색 반복과 추가 조건 검증 후 PPO 선택기/모방으로 옮긴다. 특정 상대만 개선되거나 후방 공격이 사라지면 연장/승격하지 않고 원인을 분석한다.

실행 `python -m tools.league_tail_broad_teacher_search --out runs/league_tail_broad_teacher_search_20261012`; 종료 후 `python -m tools.league_tail_broad_teacher_confirm`. 같은 출력 폴더에 중복 실행하지 않는다. GitHub는 추가 요청 전 업로드하지 않는다.
