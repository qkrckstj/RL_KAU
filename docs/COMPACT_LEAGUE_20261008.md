# 학습 상대를 205개에서 48개로 축소

**최신 상태: 사용자 요청으로 중단.** 최종 권고와 마지막113M·행동 진단 결과는 [세 모델 선택 및 중단 안내](MODEL_CHOICE_AND_PAUSE_20261008.md)를 읽는다.113M960경기는 완료·원시 검증됐고 교체 후보55.9896%,기준54.9479%,CEM6800은67.1875%였다. 후보의 작은 상승은 행동 난수를 고려한 신뢰구간이0을 포함하므로 승격 근거가 아니다. 이어32경기 정확 재생 및2,361상태 진단까지 마쳤다. 새 학습은 실행하지 않는다.

사용자가 상대 수 축소를 승인했다. 전체 205개 상대와 이전 학습 가중치는 보존하고, 실제 학습에서 불러오는 상대만 48개로 제한한다. 공식 FairFight 규칙, 원래 CEM, 보상·관측·PPO 설정은 유지한다. GitHub 업로드는 하지 않는다.

## 근거와 직전 결과

- 205개에는 많은 중간 체크포인트와 같은 모델의 행동 난수 변형이 들어 있다. 한 에피소드에는 상대 하나를 사용하므로 상대 수와 학습 시간은 정비례하지 않는다. 다만 모델 적재 비용과 경험 분산을 줄일 여지가 있다. 상대 수 감소만으로 속도나 성능 향상을 보장하지 않는다.
- 추가 학습 5,242,880단계는 완료됐다. 7600은 기준7400보다 개선되지 않았고, 7601은 1,310,720단계가 개발 평가에서 가장 좋았다. 그러나 별도110M 조건의 5,376경기에서 기존48상대 승률은 후보50.33%, 기준51.63%였다. 짝지은 차이의 조건·행동 난수 신뢰구간은 약 −4.43~+1.56%p로 개선을 확인하지 못했다. 따라서7400을 보존한다.
- 이후205상대 실행 `league_refreshed_ppo_train_20261008`은 첫1,310,720단계 저장을 마친 뒤 사용자가 승인한 축소 전환으로 중단했다. 개발 평가의 선택 지표는 기준0.64277에서 후보0.62494로 낮아져 기준을 유지했다. 이는 승률 그 자체가 아닌 결합 선택 지표다. 이 실행 전체를 완료 실험으로 취급하지 않는다.
- 저장 위치: `refreshed/s7600/checkpoints/step_1310720/learner.zip`. SHA256: `33fdd1b9acc64f5023749d55894efce8973256ef52873a29b339621cf17aca17`. 중단 기록은 해당 실행의 `user_requested_transition.json`이다. 저장 뒤 추가 진행분은 이어받지 않는다.

## 48개 구성과 교체

`tools/league_compact_roster.py`가 선택 과정을 재현한다. 실행별 `active_roster.json`에 전체 선정 목록과 중복 판정 근거를 남긴다.

1. 원래 CEM, 기존 우수 CEM, 기준7400, 보존7601, 기본 봇, 좌우 고정 동작, 주요 취약 상대를 필수로 포함한다.
2. 27개 코드 계열을 모두 포함하며 계열별 최대4개로 제한한다. 같은 코드가 같은 행동이라는 가정은 하지 않는다.
3. 동일 소스 및 actor·teacher 파일의 바이트 해시가 일치하는 경우에만 고정 행동 난수 변형을 묶는다. 확인된44쌍을 대표화하면 후보161개다. 다른 형식의 정책은 임의로 동등 처리하지 않는다.
4. 부족하게 포함된 계열을 먼저 채우고, 같은 계열에서는 기준7400이 어려워한 상대를 우선한다.109M/110M의 관측된 결과를 쓰므로 미관측 평가라는 주장은 하지 않는다.
5. 실험 도중에는 목록을 바꾸지 않는다. 다음 실험을 시작할 때 이전 명세를 지정하면 필수 상대와 계열 범위를 유지하며 최대8개를 같은 계열 안에서 교체할 수 있다. 전체 기록은 보존하며 넓은 상대 평가는 후보가 생겼을 때 별도로 수행한다.

## 이번 학습

- 검증된7400의 actor·critic·Adam을 복원한다. 시뮬레이터 상태까지 정확히 재개하는 것은 아니다.
- 서로 다른 난수7800/7801에 각각1,310,720단계, 총2,621,440단계를 먼저 추가한다. 두 실행은 같은 학습된 조상에서 출발한다.
- CPU 작업자8개, 가상 환경32개. 스레드 환경 변수3개는 모두1이다.
- 훈련 조건304M/305M. 개발 평가는 이전205상대 실행의111M·40상대·양 진영을 그대로 사용한다. 이는 비교용 개발 조건이며 최종 미관측 시험이 아니다. 학습 상대48개와 평가 상대40개는 목적이 다르다.
- 현재 고정 실행에는 자동 연장하지 않는다. 두 결과와 상대별 퇴행을 분석해 후속 실행의 추가 예산·교체를 결정한다. 이전 모델이 더 좋으면 유지한다.

실행은 `aircombat-rl`에서 `.venv-cpu` Python을 사용한다. 먼저 `tools.league_compact_ppo_train --smoke --out runs/league_compact_ppo_smoke_20261008`, 통과 후 `tools.league_compact_ppo_train --out runs/league_compact_ppo_train_20261008`를 실행한다. 기존 실행이 살아 있으면 중복 실행하지 않는다. 이미 존재하는 출력 경로는 재사용하지 않는다. 원본 입력과 소스는 해시로 고정한다. 검증기는 `tools.league_compact_ppo_analysis`이며 실제 저장·복원, 학습 설정, 상대 확률, 평가 원시 기록과 최적 모델 보존을 확인한다.

## 첫48개 학습 완료와 제외 상대 평가

2,621,440단계, 개발 평가960경기가 완료되고 원시 기록·설정·저장 검사를 통과했다. 같은111M 개발 조건의 기준 승률58.125%에서7800은59.375%,7801은54.375%였다. 동일 최종 학습량의 두 실행 평균은56.875%로 기준보다 낮다.7800만 새 체크포인트를 보존 대상으로 선택했고7801은 기준7400을 유지했다. 서로 다른 난수지만 같은 학습된 조상을 공유한다.

첫 모델도 개발 평가 중 활동 상대26개에서는 평균+3.85%p, 비활동 ID14개에서는−3.57%p였다. 이 구분은 ID 기준으로 같은 모델의 다른 난수 변형도 일부 포함한다. 따라서 후속 평가에서는 고정 난수 변형 및 이름상 같은 체크포인트의 형제 변형을 보수적으로 제외했다.

`league_compact_inactive_assess_20261008`의112M·24상대·4초기조건·양 진영·2행동 난수 평가960경기는82.16초에 완료됐다. 최소 커밋 여유9.50GiB. 기존에 관측한 상대 중 이번48개 학습에서 제외한 표본이며, 처음 보는 상대라는 뜻은 아니다. 후보7800 승률58.8542%, 기준7400은63.2813%, 보존CEM6800은61.4583%였다. 후보−기준은−4.4271%p, 조건·행동 난수를 함께 고려한 신뢰구간은 약−8.33~−1.04%p였다. 계열 균등 승률도62.07% 대66.41%로 낮았다.24개 표본의 조건부 결과이며 전체205개나 미래 참가자 성능으로 일반화하지 않는다. 반복 실행의 선택 모델은7400과 같은 모델이므로 중복 경기를 실행하지 않았다.

따라서7800을 대표 정책으로 승격하거나 그대로 예산을 확대하지 않는다.7400·원래 CEM·7800과7801의 가중치는 모두 보존한다. 다음은48개 중40개를 유지하고 같은 코드 계열 안에서8개를 교체하는 실험이다. 기준7400에서 원래7800/7801 난수 및304/305M 훈련 조건을 재사용해, 완료된 첫48개 실험과 비교한다. 원래 예약 파일은 보존하고 별도 짝지은 사용 기록을 남긴다. 각1,310,720단계이며 중간 상대 교체는 하지 않는다. 교체 후보는 `league_compact_roster.select`의 사전 정의된 교체 규칙을 따른다. 이는112M 결과를 본 후 결정한 후속 학습이므로112M은 더 이상 미사용 평가가 아니다.

후속 평가 명세v1은 미실행 상태로 보존했다. v2가 행동 유지·포트폴리오 정책의 형제 난수 변형까지 보수적으로 제외하며 실제 사용됐다. 학습 상대 목록의 동등성 판정 자체를 소급 변경하지 않는다. 교체 학습도 내보낸 모델ID가 기존 후보와 충돌하지 않도록 `rotated` 이름을 쓰는v2 실행기를 사용한다.

## 8개 교체 실험 완료

`league_compact_rotated_train_20261008`도2,621,440단계 및960개 개발 평가 경기를 완료했고 원시 검사를 통과했다. `matched_roster_comparison.json`은 초기 학습 파라미터 해시, 난수·학습 조건·예산·평가 조건, 기준 모델의 모든 경기 기록이 교체 전 실험과 일치함을 확인했다.

| 학습 난수 | 교체 전48개 | 8개 교체 후 | 기준7400 |
|---|---:|---:|---:|
| 7800 | 59.375% | 56.250% | 58.125% |
| 7801 | 54.375% | 60.9375% | 58.125% |
| 같은 최종 학습량 평균 | 56.875% | 58.59375% | 58.125% |

교체7801의 계열 균등 승률은 기준보다4.61%p 높았지만, 하위4분위 점수는0.3375에서0.325로 낮아져 기존 연장 기준은 통과하지 못했다. 이 후보의 승률 차이+2.8125%p에 대한 조건·행동 난수 신뢰구간은−2.5~+11.25%p로 넓다. 2개의 개발 초기조건만 사용한 결과이며 평균의 작은 상승을 확정적인 방법 개선으로 주장하지 않는다.7800은 기준을 유지하고7801후보는 별도로 보존했다.

이전에 실패한 첫48개 후보의112M 결과를 원시 경기로 확인하면, 기준243승118무23패에서 후보226승139무19패로 바뀌었다. 동시 격추는106→120회, 시간 초과12→19회였다. 패배 증가가 아니라 승리 감소와 무승부 증가가 주요 현상이다. 이 기록만으로 보상이나 특정 행동을 원인으로 단정하지 않는다.

교체7801후보는 연장하지 않고113M 새 초기조건·양 진영·현재 비활동24개 상대에서 별도로 진단한다. 실행은 `tools.league_compact_rotated_assess`, 출력은 `runs/league_compact_rotated_assess_20261008`이다. 이 진단을 진행한다는 결정은 개발 결과를 본 후 내렸으며, 실패한 연장 기준을 소급 통과시킨 것이 아니다. 상대 명세와 후보는113M경기 전에 고정했다. 해당 상대도 과거에 관측한 계열·정책이고 이번48개 목록에서 빠졌다는 의미이므로 미관측 상대 시험이라는 주장은 하지 않는다.

## 평가 작업자 측정 결과
