# 공개 움직임으로 기존 정책을 선택하는 CEM 학습

최신 결과: 새 92M 조건·104개 상대의 3,328판 비교가 완료됐고 원시 재검증을 통과했다. 후보 승률 65.6851%, 기준 65.5649%로 개선이 거의 없고 상대 계열 균등 승률은 후보가 낮았다. 기존 모델을 유지한다. 후속 실행은 [행동 선택 주기별 PPO 학습](ACTION_HOLD_PPO_20261007.md)이다. 아래 후속 실행 시작 설명은 당시 기록이다.

## 완료 결과와 후속 실행

두 CEM 반복 모두 완료했고 종료 코드 0을 확인했다. 탐색 4,992판, 별도 개발 비교 768판, 원본 재현 검사 32판, 총 **5,792판**이다. `raw_portfolio_analysis.json`에서 원시 게임, 집계, 순위, 고정 선택과 모델 파일을 확인했다. 병렬 완료 순서에 따른 부동소수점 합산 차이는 절대 오차 1e-12만 허용했다.

| 같은 90M 개발 조건 | 승률 | 코드 계열 균등 승률 |
|---|---:|---:|
| 기존 PPO | 63.671875% | 67.489035% |
| CEM 선택기 6400 | 56.640625% | 55.893640% |
| CEM 선택기 6401 | 68.75% | 74.862939% |

두 반복 평균 승률은 62.6953125%로 기준보다 낮다. 따라서 방법 전체의 안정적 개선으로 결론 내리지 않는다. 다만 개발 순위가 가장 높은 6401 후보는 새 조건·넓은 상대 비교를 진행할 가치가 있다. 이 후보의 weave 결과는 3승 2무 3패로, 기준의 8패보다 나았다. extend_right는 양쪽 모두 8패, evader는 모두 8무였다. 약점 둘은 여전히 해결되지 않았다.

후속 `runs/league_portfolio_transfer_20261007`는 개발 결과만으로 후보 `portfolio_s6401_g2_c2`를 고정한 뒤 시작했다. 새 92M 조건 4개·양 진영·행동 난수 두 개·104개 기존 상대에 대해 후보와 기준 모델의 **3,328판**을 비교한다. 작업자는 8개이며 새 포트폴리오 정책은 일반 로더를 사용한다. 학습 패널 13개와 나머지 91개 상대를 나누어 보고한다. 91개는 선택기 CEM 학습 패널 밖의 상대이지, 기반 전문가까지 전혀 보지 않은 상대라고 주장하지 않는다. 승격·최종 시험·미사용 상대 시험은 아직 하지 않았다.

행동 유지(0.25/0.5초) 진단 코드와 초기화 검사는 준비했지만 실행하지 않았다. 이 비교 결과에 따라 후속 PPO 학습 또는 선택기 확장을 결정한다. 기존 모든 가중치와 원시 기록은 보존했다.

## 전환 근거

`league_weakness_geometry_20261007` 진단 312판이 종료 코드 0으로 완료됐고 `raw_geometry_analysis.json`에서 동결된 입력·원시 승패·진영·초기 조건·기록을 확인했다. 계측 유무 비교 72판도 원래 대결과 일치했다.

| 정책 | extend_right 승/무/패 | weave_right 승/무/패 | evader 승/무/패 |
|---|---:|---:|---:|
| 보존한 현재 PPO | 0/0/16 | 0/4/12 | 0/16/0 |
| 보존한 CEM 교사 | 0/0/8 | 1/2/5 | 6/2/0 |
| 집중 학습 PPO 6300 | 0/0/16 | 3/4/9 | 0/16/0 |
| 집중 학습 PPO 6301 | 0/0/16 | 8/4/4 | 0/16/0 |
| Ace | 2/0/6 | 3/0/5 | 2/6/0 |

PPO 세 종류는 evader에게 한 번도 피해를 주지 못했다. CEM은 피해를 준 6판 모두 승리했으며 최초 공격 시각의 중앙값은 약 108.8초였다. extend_right에는 현재 PPO와 집중 학습 PPO 모두 패배했다. 이는 각 정책의 약점과 장점이 다르다는 근거이며, 충분히 학습하면 해결된다는 증거는 아니다. 4개 초기 조건의 두 진영, PPO는 두 행동 난수 반복이다. 아직 새 상대나 전체 대회 성능의 증거가 아니다.

## 실제 후속 실험

`aircombat-rl/runs/league_portfolio_train_20261007`에서 **CEM으로 정책 선택기의 계수를 학습**한다. PPO 가중치를 추가 업데이트하는 실험과 구분한다. 네 전문가(현재 PPO, CEM 교사, 집중 학습 PPO 두 개)의 파일은 그대로 보존하고 복사본을 묶는다.

초기 0.5~6초는 현재 PPO로 비행한다. 상대의 공개 관측에서 회전량, 속도 변화, 기수 변화, 접근 속도를 누적한 뒤 전문가 하나를 선택한다. 상대 이름·봇 ID·내부 상태·미래 정보는 입력하지 않는다. 방향의 부호에 의존하지 않는 특징과 고정 전문가로 시작하며, 선택된 전문가는 이후에도 매 시점 관측에 반응한다. 전문가들의 상태와 행동 난수는 실제 비행한 초반 관측으로 초기화한다.

두 CEM 난수 반복(6400/6401), 반복당 3세대·세대당 8후보로 제한한다. 매 세대 기존 최선과 항상 현재 PPO를 선택하는 후보를 포함한다. 탐색은 다양한 기존 상대의 소규모 패널, 같은 초기 조건과 양 진영, 행동 난수 두 개로 비교한다. 전체 104개 상대와 이전 모델은 보존한다. CEM 학습 조건은 284M/285M, 개발 평가는 별도 90M 조건이다. 전문가 선정은 결과 확인 전에 고정했다.

실제 대결에서 각 전문가를 그대로 선택하는 포장 정책이 원본과 동일한 에피소드와 승패를 내는지 32판으로 확인한 뒤 CEM 탐색에 들어간다. 초반 관측의 인과성·좌우 대칭·에피소드 초기화 검사는 2개 모두 통과했다. 작업자 8개, 시작 시 커밋 여유 약 14.2GiB이다.

이 실험은 기존 정책의 장점 보존 가능성을 확인하는 제한된 탐색이다. 특히 모든 전문가가 약한 extend_right를 해결한다고 가정하지 않는다. 개발 결과로 기존 정책의 대체 여부와 다음 신경망 학습/전문가 확장 필요성을 판단한다. 최종 평가나 미사용 상대 평가를 열지 않았고 자동 승격하지 않는다. GitHub 업로드는 하지 않는다.

실행 명령(코드 디렉터리, 세 스레드 환경 변수를 1로 설정):

```powershell
& '.venv-cpu\Scripts\python.exe' -X utf8 -u -m tools.league_portfolio_train --source runs/league_weakness_geometry_20261007 --out runs/league_portfolio_train_20261007
```

기존 실행 경로로 중복 실행하지 않는다. 재개 시 실제 프로세스와 completion/failure 파일을 먼저 확인한다. 완료한 후보·세대 결과는 덮어쓰지 않고 보존한다.
