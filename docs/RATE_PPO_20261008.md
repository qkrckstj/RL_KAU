## 추가 학습 이후의 표본 대결 계획

첫 추가 학습 체크포인트 성적을 보기 전에 `experiments/league/rate_budget_screen_protocol_20261008.json`을 고정했다. 기존 전체197개 상대 평가에서7400의 점수가 낮았던8개, 패배율 증가가 컸던4개, 이미 평가한 파라미터 조합8개·전환 정책8개를 포함한다. 여기에 기존27개 코드 유형이 모두 포함되도록 추가하고, 고정된 해시 순서로48개 상대를 채웠다. 겹치는 상대는 중복 집계하지 않는다.

추가 학습에서 생성될 첫/마지막 체크포인트의 행동 난수별 상대8개를 더해 총56개 상대를 평가한다. 개발 결과로 고른 두 보존 모델, 출발7400, 순수 교사, CEM6800을 새로운110M 초기 조건8개·양 좌석에서 비교한다. 확률 정책은 행동 난수2개씩, 결정론적 정책은1개씩 사용하므로 최대7,168경기다. 보존 모델이 출발 모델과 같으면 실제 경기를 중복 실행하지 않는다. 전체197개 상대를4개 조건에서 비교했던 이전 평가보다 경기 수는 줄고, 상대당 초기 조건 수는 두 배다. 이는 전체 상대 승률의 추정이 아닌 후속 진단이며, 모든 과거 모델은 계속 보존한다. 유망한 결과의 최종 확인은 독립 반복과 추가 미사용 조건/상대 증거를 별도로 요구한다.

`runs/league_rate_ppo_assess_20261008`에서 후속 대결15,760경기를 시작했다.109M의 새로운 초기 조건4개·양 좌석을 사용한다. 개발 결과로 사전 선택한 기존 학습률 두 후보, 낮은 학습률7401 후보, 공통 출발 모델, 순수 교사 및 CEM6800을 비교한다. 확률 정책은 행동 난수2개, 결정론적 제어기는1개씩 실행한다.

상대는 기존 학습 상대173개, 이번 실험의 첫·마지막 체크포인트16개, 새 전술 파라미터 조합8개로 나눠 보고한다. 새 조합은 난수7501을 고정해 기존7개 파라미터 범위에서 계층화 추출했다. 경기 성적을 보고 고르지 않았고 학습 상대에 포함하지 않았다. 기존 제어기와 같은 코드 계열이므로 새로운 구조나 실제 수강생 모델에 대한 일반화로 해석하지 않는다. 대결 후에는 이 조합도 이미 사용한 평가로 분류한다.

기존 기본·취약 상대 집중 학습은 두 번째 구간에서 출발 모델보다 평균 승률이 낮아졌다. 새 조건 평가에서 첫 기본 후보는 개선됐지만 다른 반복은 개선되지 않았다. 다음 실험은 업데이트 크기를 줄여 학습 중 성능 하락을 완화할 수 있는지 확인한다.

- 출발: `league_prioritized_ppo_train_20261008/control/s7300/checkpoints/step_1310720/learner.zip`. 개발 평가에서 선택한 모델이며 최종 우승 모델이 아니다.

- 상대: 기존157개와 새 체크포인트16개, 총173개.107M 평가를 소비해 상대별 실패율을 갱신하며 모든 상대의 선택 확률을 양수로 유지한다.

- 모델과 Adam 모멘트는 그대로 복원한다. 스케줄만 바꾸고 실제 PPO 업데이트에서 optimizer 학습률이 바뀌는지, 저장 후에도 설정과 Adam이 복원되는지 검사한다.
- 학습 전81,920단계 통합 점검을 실시한다. 점검과 본 학습의 소스 해시가 같아야 본 학습을 시작할 수 있다.

실행기는 `aircombat-rl/tools/league_rate_ppo_train.py`, 검증기는 `tools/league_rate_ppo_analysis.py`다. 기존 학습 실행기와 원시 검사 코드는 변경하지 않는다. 새 출력은 `runs/league_rate_ppo_smoke_20261008` 및 `runs/league_rate_ppo_train_20261008`을 사용한다. 일반적인 PPO 정확성 전체를 증명하는 검사가 아니라 이번 실행의 설정·원시 결과·저장·복원 검증이다.

두 반복은 같은 학습된 조상을 공유한다. 미지의 참가자에 대한 보편적 우위나 처음부터의 독립 학습 재현으로 해석하지 않는다. 기존 CEM·PPO·공식 FairFight 규칙과 모든 체크포인트를 보존하며 GitHub 업로드는 제외한다.

## 실행 중 코드 확인

`residual_ppo_policy.py`의 정책은 교사 행동만 허용하는 마스크를 사용하지 않는다. 공식 이산 행동 9개 전부에 확률을 부여하며, 신경망 출력에 교사 행동의 logit 편향6을 더한다. 신경망의 잔차 출력이 전부0인 초기 상태에서 교사 행동 확률은 `exp(6)/(exp(6)+8)`, 약98.06%다. 현재 학습된 모델은 잔차 출력이 있으므로 이 숫자를 현재의 교사 추종률로 사용하면 안 된다. 현재 결과만으로 이 편향이 성능 정체 원인이라고 단정하지 않는다.

공식 행동은 방향 변화 -30/0/+30도와 속도 변화 -20/0/+20kt의 조합이다. 기존 학습 래퍼는 모델이 선택한0~8 행동을 그대로 환경으로 전달한다. 따라서 현재 약점을 단순히 특정 공식 행동이 차단돼 생긴 문제로 볼 근거는 없다. 학습 중인 소스·물리·행동 공간·보상은 수정하지 않았다.
