## 이관 당시 기록

대상은 사람의 학습 일정이 아니라 수업용 **JSBSim 항공기 정책 학습**이다.
FairFight 중심이며, 고도 목표는 고정이고 정책은 방향·속도 명령을 선택한다.
공식 물리·자동조종기·상대·무장·평가 규칙은 변경하지 않았다.

### 완료한 작업

1. Windows Python 3.12 별도 환경, Intel XPU 작동 확인.
2. CPU/XPU 비교: 작은 Circular DQN에서 CPU 1스레드가 약 2.83배 빨랐다. 일반적인 GPU 성능 결론은 아니다.
3. 원본 DQN 20만 스텝 재현: 별도 시험 0/40.
4. 기본 관측 DQN·31개 관측 DQN·같은 관측 PPO를 각 204800스텝 × 3시드로 비교.
5. 개선 관측 DQN을 1024000스텝 × 3시드로 추가 비교. 초반 204800스텝의 가중치와 검증 경기 결과는 이전 실행과 정확히 일치했다.
6. 재개 명령과 다른 컴퓨터 설치 안내 추가. 원본 체크포인트를 덮어쓰지 않는 재개 경로 검증.

### 현재 상태

100만 예산에서 검증 선택 모델의 시험 승리는 seed별 10/40, 6/40, 10/40,
평균 21.67%다. 실제 선택 시점은 819200, 972800, 204800이다.
마지막 1024000스텝 모델은 모두 시험 0승으로, 수렴과 성능 유지가 불안정하다.
대표 모델은 `aircombat-rl/runs/plan_a_20261001/duration/selected_policy/`에 있다.
기존 대표 정책과 같은 가중치이며, 새 시험의 25%를 이전 시험 17.5% 대비 학습 향상으로 해석하면 안 된다.

이관 당시 실행 중인 학습 작업은 없었다. GitHub 이관은 추가 대규모 학습을 시작하지 않았다.

### 유지할 실험 조건

- FairFight, red 좌석 학습, 평가 시 red·blue 모두 사용.
