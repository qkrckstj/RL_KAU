# 후방 공격 경험을 위한 상대 분포 단계화

목표는 원래 FairFight 조건에서 다양한 상대에게 후방 공격을 전이시키는 것이다. 64경기 가능성 점검에서 기존 저장 PPO도 fixed_right 및 과거 residual3301 상대에게 무피격 승리와 실제 후방 피해를 재현했다. Circler는 쉬운 회전 상대에 성능이 몰리는 것을 피하기 위해 집중 대상에서 제외한다. 이 점검은 훈련 대역에서 수행했으며 독립 최종 시험이 아니다.

## 변경 요인

상대 선택 분포만 바꾼다. 매 두 경기 선택 중 한 번은 기존 48상대 순회, 나머지는 가중 추첨이라는 구조를 보존한다. 가중 추첨에서 초반에는 위 두 상대를 균등 선택하고, 환경당 물리 10,240단계까지 원래 확률로 선형 복귀한다. 이후는 원래 확률을 유지한다. 32환경이므로 총 327,680단계에 해당한다. 확률 변경은 새 경기 시작 때 적용하며 진행 중인 상대를 교체하지 않는다. 따라서 전환 경계를 걸친 경기는 다음 초기화까지 유지된다.

기존 부모의 actor/critic/Adam을 복원한다. 같은 부모·학습 난수10100/10101·이미 사용한 초기조건 대역441M/442M·각655,360단계로 기존 실제후방피해 .5 대조군과 비교한다. 총 새 PPO 1,310,720단계. 기존 대조군 학습은 재사용한다. 독립적으로 처음부터 학습한 반복이라고 부르지 않는다.

quarter 출발50%, 위치 보상 .01, 후방 실제피해 .5, 기존 잠재 보상, prior6, gamma .999 및 나머지 PPO 설정은 그대로다. 이전에 미채택한 정렬 잠재 보상 .25는 추가하지 않는다. 원래 물리·무장·종료와 round4 종료체력 판정, 기존 CEM/PPO 파일은 보존한다. CPU8작업자32환경, 시작 커밋여유4.5GiB/초기화후2.8GiB 및 런타임 보호 유지.

## 확인과 평가

분포 변경을 끈 양좌석 전체 경기의 관측·체력·보상·종료 일치, 명시적 재시드, 단계 경계와 전체 상대 순회 보존 테스트3개 통과(9.02초). 실학습 20,480단계 통합 점검은 별도 폴더에서 실행한다. 본 학습은 점검 모델이 아니라 원래 부모에서 시작한다.

24상대×초기조건2개×양좌석×행동난수2개×후보/대조4모델 = 768경기. 이 중 대조384경기는 원래 체력·승패·시간·후방 사격권 기록과 정확히 일치하는지 확인한다. 소비한 개발 조건이며 미사용 최종 시험이 아니다. 승률·실제 후방 피해·피격·정면 피해를 상대별로 비교하고 Circler 외 전이를 따로 본다. 두 반복의 개선이 엇갈리거나 쉬운 상대에만 집중되면 장기 연장하지 않는다. 유망할 때만 별도 난수·미사용 조건 검증으로 넘어간다.

실행 도구: `tools/league_rear_opponent_experiment.py`, `tools/league_rear_opponent_train.py`, `experiments/league/rear_opponent_curriculum.py`. 실행 전에 입력·소스 해시를 동결한다. 기존 출력 디렉터리에는 재실행하지 않는다. 완료 후 경기 수와 학습/평가/전체 시간을 별도 보고한다. GitHub 추가 업로드 없음.
