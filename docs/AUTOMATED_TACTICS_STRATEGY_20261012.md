# 현재 자동 학습 전략 — 2026-10-12 업데이트

## 현재 결론

목표는 다양한 상대에게 이기면서 정면 피해 교환을 줄이고 후방 진입·추적·공격을 익히는 것이다. **새 후방 전술 후보가 기존 CEM/PPO를 대체할 만큼 좋아졌다는 근거는 아직 없다.** 기존 모델은 보존한다. 최근 완료한 실험은 후방 피해 보상 0.5→1.0 비교이며 채택하지 않았다. 다음 단계는 낮은 피격과 후방 공격을 함께 달성하는 별도 교사 후보 탐색이다. 이 단계는 아직 실행 완료된 결과가 아니다.

PDF를 모델의 입력으로 넣어 학습하는 것은 아니다. 논문의 아이디어를 보상, 훈련 조건, 전문가 구성과 평가 방법으로 구현하고 실제 경기에서 검증한다. 아래 표는 적용과 미적용을 구분한다.

## 유지하는 규칙과 자동화 구조

- 원래 FairFight 물리·무장·종료 시점 보존. 승패는 종료 체력을 소수점 네 자리로 반올림하여 비교한다. 높은 쪽 승리, 같으면 무승부(`user_terminal_health_round4_v2`).
- 기존 CEM6800, PPO, 과거 상대와 동결 실험을 덮어쓰지 않는다. 평가에서는 원래 FairFight 시작 조건을 사용한다.
- PPO 학습은 CPU 작업자 8개·환경 32개, 훈련 상대 48종을 사용했다. 경기 평가와 교사 탐색은 별도 작업이며 PPO 단계로 합산하지 않는다.
- 실행기가 학습·평가·저장·검사를 수행하고, 활성 Goal 에이전트가 결과를 분석해 다음 실험을 선택한다. 실행기 하나가 에이전트 없이 무한히 전략을 바꾸는 구조는 아니다.
- 각 주기마다 실제 물리 단계, 정책 선택 횟수, 완료 훈련 경기, 신규/재사용 평가 경기, 학습/평가/전체 시간을 구분한다.
- 기존 프로세스 종료 및 결과를 확인한 뒤 다음 실행을 시작한다. 메모리 보호와 입력 해시 검사를 유지한다. GitHub 업로드는 사용자 명시 요청 때만 한다.

## 실제로 비교한 전략

1. 기존 PPO를 이어받아 위치 보상, 실제 후방 피해 보상, 거리·시작 방향 커리큘럼, 기존 행동 유지 제약을 비교했다. 종합 개선이 없는 설정은 장기 연장하지 않았다.
2. 별도 CEM 계열 파라미터 탐색으로 후방 공격 교사를 만들었다. Ace에서는 후방 공격 사례가 있었지만 피격이 컸고 다른 상대에 대한 전이가 약했다.
3. 성공 직전 8초, 16초, 전체 접근 궤적을 모방했다. 실제 경기 승률과 후방 공격이 함께 개선되지 않아 채택하지 않았다. 모방 손실 감소만으로 성공이라고 판단하지 않았다.
4. 기존 PPO·실제 CEM6800·후방 교사를 동결하고 **새 PPO 선택기만** 학습했다. 이 선택기는 새로 초기화했으며 전문가 모델들은 처음부터 다시 학습하지 않았다.
5. 0.05초마다 전문가를 바꾸는 방식과 전문가 선택을 1초 유지하는 방식을 비교했다. 후자는 조종 입력을 1초 고정하는 방식이 아니다. 선택된 전문가가 매 0.05초마다 관측에 따라 조종한다. 보상 할인과 단계 집계를 이에 맞췄다.
6. 1초 선택기의 실제 후방 피해 보상만 0.5에서 1.0으로 올렸다. 두 반복의 승률 변화가 엇갈리고 Circler 외 후방 피해 발생은 그대로여서 1.0을 채택하지 않았다.

**명칭 정정:** 기존 PPO 관측에 들어가는 행동 사전은 상태를 갖는 `temporal_extend_right`이며 CEM이 아니다. 선택기 전문가로 사용하는 실제 CEM6800과 별도 인스턴스로 관리한다. 과거 문서에서 이를 CEM 사전이라고 부른 표현은 부정확했다.

## 최근 완료 결과

| 실험 | 실제 물리 단계 | 신규 평가 / 재사용 | 학습 / 평가 / 전체 시간 | 판단 |

| 0.05초 전문가 선택 | 1,310,720 | 864 / 0 | 275.99 / 118.07 / 503.34초 | 초기 76.04%→68.23%, 63.02%; 채택 안 함 |
| 1초 전문가 선택 | 1,298,453 | 576 / 288 | 136.11 / 88.10 / 337.16초 | 자체 초기 54.17%→58.33%, 61.98%; 단독 전문가보다 낮음 |
| 1초 선택기 후방 보상 1.0 | 1,298,440 | 384 / 864 | 136.41 / 64.82 / 310.57초 | 0.5 대조 대비 58.33→57.29%, 61.98→62.50%; 채택 안 함 |

1초 실험들은 각 65,536번의 정책 선택을 수행했다. 마지막 실험의 완료 훈련 경기는 1,165회다. 전체 시간에는 초기화·저장·검사가 포함된다. 두 방식의 초기 성능 자체가 다르므로 최종 수치만으로 유지 시간의 효과를 단정하지 않는다. 마지막 1,248개 평가 셀은 신규 384개와 재사용 864개의 합이며 새로 1,248경기를 돌렸다는 의미가 아니다.

같은 개발 패널의 단독 전문가 승률은 PPO 70.83%, CEM6800 72.92%, 후방 교사 20.83%였다. 선택기와 전문가의 행동 샘플링·반복 수도 구분해야 한다. 이는 미지 참가자나 독립 최종 시험의 성능이 아니다. 개발 조건과 난수 대역을 방법 간 대응 비교에 재사용했으며, 독립적인 새 반복이라고 부르지 않는다.

후방 사격권 체류는 실제 피해가 아니다. 실제 후방 피해는 이동 후 기하와 해당 물리 단계의 체력 감소로 계산한다. 보상 1.0의 Circler 외 후방 피해 경기는 두 반복 모두 2회로 대조와 같았다. 저장된 96개 조건에서 세 전문가 중 승리·후방 피해·무피격을 함께 달성하는 선택지가 있는 조건은 4개였다. 이것은 사후 전체 경기 분석이지 경기 중 전환 정책의 성능 상한은 아니다.

## 다음 실행과 자동 판단

먼저 별도 교사를 더 다양한 상대에게 평가하며 탐색한다. 승률·실제 후방 피해와 함께 받은 피해 및 종료 체력을 고려한다. 높은 피격을 감수한 후방 공격만 보상하지 않도록 탐색 목적을 설계하되, 평가 승패 규칙은 바꾸지 않는다. 구체 계수·상대 목록·예산은 다음 실행의 동결 계획에서 확정한다.

새 교사는 기존 교사와 같은 조건·양 좌석에서 비교한다. 후방 피해 증가가 승률 하락이나 피격 증가를 동반하면 채택하지 않는다. 여러 상대에서 개선이 나타나는 교사가 확보됐을 때만 전문가 목록에 추가하거나 시범 학습을 재개한다. 좋은 교사 없이 선택기의 보상 계수만 계속 바꾸지 않는다.

유망한 후보는 추가 학습 난수와 더 넓은 상대군으로 확인하고, 개선 추세가 재현될 때 예산을 늘린다. 이미 본 조건은 개발 평가로 유지한다. 최종 채택에는 학습·선정에 쓰지 않은 조건/상대 평가와 경기 영상 확인이 필요하다. 개선되지 않으면 관측·접근 궤적·피격 시점과 실제 보상 지급을 분석하여 다음 한 요인을 바꾼다.

## 이번 공개 범위

현재 전략·결과·논문 및 최신 집계 근거를 업데이트한다. 모든 최신 로컬 체크포인트와 원시 경기·동결 의존성을 포함한 재개 패키지는 아니다. 새 컴퓨터에서 이 문서만으로 최신 학습을 그대로 재개할 수 있다고 주장하지 않는다. 이전 실행 기록은 Git 이력 및 각 상세 문서로 보존한다.
