> **최신 사용자 지시 (2026-10-12):** 정면 교전 CEM/PPO는 보존하고 후방 전술을 별도 계보로 계속 개발한다. 승률 하락만으로 후방 후보를 버리지 않는다. [새 계획](REAR_BRANCH_PLAN_20261012.md)이 과거 승률 중심 미채택·중단 지침보다 우선한다. 이번 게시만 승인되었으며 이후 GitHub 자동 업로드는 금지한다.

# 현재 자동 학습 전략 — 2026-10-12 업데이트

## 현재 결론

현재 최우선 방향은 [후방 전술 독립 개발 계획](REAR_BRANCH_PLAN_20261012.md)이다. 정면 교전 기준 모델은 보존하면서, 후방 후보는 승률이 낮아도 전술 발전 대상으로 남긴다. 최신 조건별 상대 비중 실험은 종합 승률과 다양한 상대 전이에서 개선되지 않았지만, 사용자가 확인한 Circler 후방 무피격 승리 모델을 별도 후방 계보 후보로 보존한다. 아래 미채택 기록은 당시 종합 기준의 역사이며 새 개발 지시와 구분한다.

PDF를 모델의 입력으로 넣어 학습하는 것은 아니다. 논문의 아이디어를 보상, 훈련 조건, 전문가 구성과 평가 방법으로 구현하고 실제 경기에서 검증한다. 아래 표는 적용과 미적용을 구분한다.

## 유지하는 규칙과 자동화 구조

- 원래 FairFight 물리·무장·종료 시점 보존. 승패는 종료 체력을 소수점 네 자리로 반올림하여 비교한다. 높은 쪽 승리, 같으면 무승부(`user_terminal_health_round4_v2`).
- 기존 CEM6800, PPO, 과거 상대와 동결 실험을 덮어쓰지 않는다. 평가에서는 원래 FairFight 시작 조건을 사용한다.
- PPO 학습은 CPU 작업자 8개·환경 32개, 훈련 상대 48종을 사용했다. 경기 평가와 교사 탐색은 별도 작업이며 PPO 단계로 합산하지 않는다.
- 실행기가 학습·평가·저장·검사를 수행하고, 활성 Goal 에이전트가 결과를 분석해 다음 실험을 선택한다. 실행기 하나가 에이전트 없이 무한히 전략을 바꾸는 구조는 아니다.
- 각 주기마다 실제 물리 단계, 정책 선택 횟수, 완료 훈련 경기, 신규/재사용 평가 경기, 학습/평가/전체 시간을 구분한다.
- 기존 프로세스 종료 및 결과를 확인한 뒤 다음 실행을 시작한다. 메모리 보호와 입력 해시 검사를 유지한다. GitHub 업로드는 사용자 명시 요청 때만 한다.

## 실제로 비교한 전략

1. 기존 PPO를 이어받아 위치 보상, 실제 후방 피해 보상, 거리·시작 방향 커리큘럼, 기존 행동 유지 제약을 비교했다. 종합 개선이 없는 설정은 장기 연장하지 않았다.
2. 별도 CEM 계열 파라미터 탐색으로 후방 공격 교사를 만들었다. Ace에서는 후방 공격 사례가 있었지만 피격이 컸고 다른 상대에 대한 전이가 약했다.
3. 성공 직전 8초, 16초, 전체 접근 궤적을 모방했다. 실제 경기 승률과 후방 공격이 함께 개선되지 않아 채택하지 않았다. 모방 손실 감소만으로 성공이라고 판단하지 않았다.
4. 기존 PPO·실제 CEM6800·후방 교사를 동결하고 **새 PPO 선택기만** 학습했다. 이 선택기는 새로 초기화했으며 전문가 모델들은 처음부터 다시 학습하지 않았다.
5. 0.05초마다 전문가를 바꾸는 방식과 전문가 선택을 1초 유지하는 방식을 비교했다. 후자는 조종 입력을 1초 고정하는 방식이 아니다. 선택된 전문가가 매 0.05초마다 관측에 따라 조종한다. 보상 할인과 단계 집계를 이에 맞췄다.
6. 1초 선택기의 실제 후방 피해 보상만 0.5에서 1.0으로 올렸다. 두 반복의 승률 변화가 엇갈리고 Circler 외 후방 피해 발생은 그대로여서 1.0을 채택하지 않았다.

**명칭 정정:** 기존 PPO 관측에 들어가는 행동 사전은 상태를 갖는 `temporal_extend_right`이며 CEM이 아니다. 선택기 전문가로 사용하는 실제 CEM6800과 별도 인스턴스로 관리한다. 과거 문서에서 이를 CEM 사전이라고 부른 표현은 부정확했다.

후방 사격권 체류는 실제 피해가 아니다. 실제 후방 피해는 이동 후 기하와 해당 물리 단계의 체력 감소로 계산한다. 보상 1.0의 Circler 외 후방 피해 경기는 두 반복 모두 2회로 대조와 같았다. 저장된 96개 조건에서 세 전문가 중 승리·후방 피해·무피격을 함께 달성하는 선택지가 있는 조건은 4개였다. 이것은 사후 전체 경기 분석이지 경기 중 전환 정책의 성능 상한은 아니다.

## 최신 후속 실험과 현재 판단

선택기 이후 교사 탐색의 체력 가중, 상대 확대, 후방 목표점 추가와 공동 파라미터 탐색을 비교했다. 훈련에서 좋아진 후보도 개발 경기에서 후방 공격과 승률을 함께 개선하지 못해 승격하지 않았다. 상세 근거는 [체력 가중](HEALTHY_REAR_TEACHER_20261012.md), [상대 확대](BROAD_REAR_TEACHER_20261012.md), [후방 목표점](REAR_TARGET_SCREEN_20261012.md), [공동 탐색](REAR_TARGET_JOINT_20261012.md)에 있다. CEM 탐색의 시뮬레이션 단계는 PPO 학습 단계와 별도다.

[궤적 진단](REAR_TRAJECTORY_DIAGNOSIS_20261012.md) 80경기 재생에서는 일부 PPO/CEM이 적 후방 거리대에 도달해도 기수를 적 쪽으로 정렬하지 못했다. 제한된 진단 표본이며 모든 상대의 일반적 원인으로 단정하지 않는다.

이에 기존 PPO 부모와 옵티마이저를 복원하고 **정렬 잠재 보상 .25만 추가**한 대응 실험을 했다. 새 PPO 1,310,720단계, 완료 훈련 1,361경기, 학습 262.35초, 평가 768경기 96.52초, 준비·검사 포함 전체 471.59초였다. 평가에는 새 후보 384경기와 기존 대조 재생 384경기가 포함된다. 두 반복의 승률은 각각 68.23→73.44%, 77.60→72.92%로 엇갈렸고 Circler 외 후방 공격도 일관되게 늘지 않았다. **추가 정렬 보상을 채택하거나 같은 설정을 장기 연장하지 않는다.** [상세 결과](REAR_ALIGNMENT_PPO_20261012.md).

그 뒤 저장된 네 정책을 원래 FairFight 시작 조건에서 4상대·2초기조건·양 좌석으로 확인했다. 추가 학습 없이 **64경기, 23.84초**다. fixed_right, 과거 residual3301 정책, Circler에 대해서는 네 정책 모두 각각 4경기에서 무피격 승리와 실제 후방 피해를 보였다. ddqn_s0에서는 대부분 후방 피해가 없고 피격도 컸다. 이는 소비한 훈련 난수 대역의 작은 가능성 점검이지 새 최종 시험이나 새 모델의 우위 증명이 아니다. 상세: [상대 분포](REAR_OPPONENT_CURRICULUM_20261012.md), [피격 벌점](REAR_RECEIVED_PENALTY_20261012.md), [학습량](REAR_BUDGET_LADDER_20261012.md), [GAE](REAR_GAE_20261012.md), [학습률·명령 진단](REAR_LEARNING_RATE_20261012.md).

기존 상대를 보존하고 승률, 상대별 최저 성능, 실제 후방 피해, 받은 피해를 함께 본다. 쉬운 상대만 잘 잡거나 Circler에만 후방 피해가 늘면 채택하지 않는다. 개선 추세가 반복되면 학습량을 늘리고, 반복되지 않으면 궤적과 지급 보상을 분석해 다른 한 요인을 검토한다. 기존 모델은 계속 보존한다.

이미 본 조건은 개발 평가로 유지한다. 최종 채택에는 추가 학습 난수와 학습·선정에 쓰지 않은 조건/상대 평가, 경기 영상 확인이 필요하다. 매 주기 학습 단계·완료 훈련 경기·신규/재사용 평가 경기·학습/평가/전체 시간을 보고한다. GitHub 업로드는 이번 명시적 요청 범위에서만 수행한다.
