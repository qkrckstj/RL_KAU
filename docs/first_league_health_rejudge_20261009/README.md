# 첫 리그 최종 시험의 종료 체력 기준 재판정

2026-10-09. 규칙은 `user_terminal_health_round4_v2`다. 기존 경기 종료 시 양쪽 체력을 Python `round(health, 4)`로 반올림하고 내 체력이 높으면 승리, 낮으면 패배, 같으면 무승부다. 시간 종료도 동일하게 판정한다. 사용자가 지정한 기준이며 외부 대회 규정을 독립적으로 확인했다는 뜻은 아니다.

| 정책 | 승 | 무 | 패 | 승률 |
|---|---:|---:|---:|---:|
| 기존 CEM |458|305|517|35.78125%|
| 사전 선택 `refine_2200` |1,098|126|56|85.78125%|

40개 공통 초기조건×양 진영×16상대, 정책당1,280경기다. 같은 기록의 구판정은 기존340승523무417패(26.5625%),선택993승241무46패(77.578125%)였다. 새 기준의 차이는+50.0%p다. 선택 정책과 기존 CEM의 직접 대결은 새 기준에서도80승0무0패다.

기존 원시 기록의 체력 필드를 재집계했으며 비행을 다시 실행하거나 새 모델을 학습하지 않았다. 당시 개발 자료로 미리 선택한 정책을 그대로 사용했다. 이미 소비된 과거 최종 시험이고, 새로운 미사용 확인 시험이나 현재 PPO의 성능이 아니다. 실제 다른 참가자 상대 성능은 미확인이다. 기존 신뢰구간·평가 관문은 새 판정으로 재계산하지 않았으므로 재사용하지 않는다.

## 재현

저장소 루트에서 일반 Python으로 실행한다. 추가 패키지는 필요 없다.

```powershell
python scripts/rejudge_first_league_final.py
```

- [episodes.csv](episodes.csv): 두 정책의2,560개 원시 경기에서 추출한 종료 체력·조건·구판정. 시뮬레이터의 저장 정밀도를 그대로 사용한다.
- [provenance.json](provenance.json): 원본32개 경기 묶음의 경로와 SHA-256, CSV의 SHA-256.
- [summary.json](summary.json): 새/구 집계, 상대별 결과, 직접 대결 결과.

재현 도구는 CSV 해시, 중복 경기, 정책/상대/초기조건/양 진영의 완전성, 체력 범위를 검사한다. 원본 실행 아카이브를 복원한 환경에서는 아래 명령으로 CSV도 다시 추출할 수 있다.

```powershell
python scripts/rejudge_first_league_final.py --source aircombat-rl/runs/league_20261006/followup_pool/heldout
```

원래 `experiments/league/results/final_summary.json`과 과거 결과표는 당시 구판정 기록으로 보존한다.
