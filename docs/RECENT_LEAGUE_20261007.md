# 새 정책 간 대결과 기준 정책 검토

최신 상태: 120개 상대 4,800판 평가가 완료됐고 extend_right 88.0208%, 기존 PPO 68.3333%로 우세가 유지됐다. 원시 재검증과 종료 코드 0을 확인했다. 후속 [새 기준 제어기 PPO 학습](EXTEND_TEACHER_PPO_20261007.md)이 실제 실행 중이다. 아래의 평가 진행 설명은 당시 기록이다.

## 새 모델을 상대 목록에 편입

`runs/league_recent_round_robin_20261007`에서 새 PPO 네 실행의 마지막 모델, 기존 PPO, 이전 history 모델, focal 모델 두 개, CEM 선택기 두 개, 보존한 CEM과 Ace·extend_right·weave_right·evader를 비교했다. 개발 순위가 낮은 새 모델도 제외하지 않았다. 역할 15종·행동 정책 25개이며, 서로 다른 역할의 모든 조합과 행동 난수 조합을 대결했다. 새 94M 초기 조건 두 개·양 진영으로 총 **1,160판**이다.

종료 코드 0을 확인했고 `raw_verification.json`에서 원시 경기와 행렬을 재계산했다. 공식 대칭 승패 규칙에 따라 한 경기의 승/패를 상대의 패/승으로 집계했으며 동시 격추·시간 초과는 무승부로 유지했다. 역할별 상대를 균등하게 평균해, 행동 난수가 두 개인 역할이 집계에서 두 배 가중되지 않게 했다. 이 집계는 별도 검사도 통과했다.

기존 PPO와의 직접 대결 결과는 다음과 같다. 초기 조건 두 개와 행동 난수 조합에 한정되므로 전체 대회 성능으로 일반화하지 않는다.

| 새 모델 | 승 | 무 | 패 |
|---|---:|---:|---:|
| control6500 | 10 | 4 | 2 |
| control6501 | 6 | 3 | 7 |
| hold5_6500 | 9 | 0 | 7 |
| hold5_6501 | 8 | 3 | 5 |

더 넓은 기존 개발 상대와 새 학습 정책 사이의 순위가 다르다. 하나의 승률만으로 모든 후보를 버리거나 승격하지 않고, 다양한 대결 상대를 보존한다. 원래 104개 상대에 새 PPO·focal·선택기 정책 16개를 추가해 **120개 상대 목록**을 동결했다. 목록은 이 실행의 `plan.json`에 있는 `expanded_training_archive`이다.

## 강한 출발점 후보 발견

이번 집합에서 `temporal_extend_right`의 상대 역할 균등 평균 승률은 **91.0714%**, 무승부 반점을 포함한 점수는 **94.6429%**였다. 현재 PPO와 새 PPO 네 모델, focal 두 모델, 선택기 두 모델, history, 보존한 CEM, Ace에는 전승했다. weave_right에는 3승 1패, evader에는 4무였다. 이것은 작은 새 조건 패널에서의 결과이며 전체 120개 상대 성능은 아직 확인 전이다.

이 결과는 PPO 가중치를 계속 미세 조정하기에 앞서 기준 정책 자체를 검토할 근거가 된다. 기존 CEM은 그대로 보존한다. 원래 상대로 쓰던 공개 관측 기반 extend 정책을 새 출발점으로 사용할 수 있는지 평가하며, 아직 신경망으로 새로 학습한 결과라고 부르지 않는다.

## 현재 실행

`runs/league_teacher_candidate_assessment_20261007`에서 다음 네 역할을 새 95M 조건 네 개·양 진영·120개 상대에 대해 비교한다. 기존 PPO는 행동 난수 두 개, 나머지는 결정적 정책 하나씩이어서 총 **4,800판**이다. 두 extend 방향은 결과를 보기 전에 모두 고정했다.

- `candidate`: 보존한 현재 PPO. 이 실행에서 필드 이름이 신규 후보를 뜻하지 않는다.
- `warm`: 기존 extend_right.
- `early`: 기존 extend_left.
- `teacher`: 원래 CEM 교사.

기존 검증된 평가 엔진을 재사용하므로 차이 집계의 부호는 **PPO − 비교 정책**이다. 음수면 extend 또는 CEM이 더 좋다는 뜻이다. 이 역할 의미를 다음 에이전트가 혼동하지 않아야 한다.

작업자는 8개(검증된 NumPy 전용 4개, 일반 4개)이다. 새 hold/portfolio 등 미검증 소스 계열은 일반 로더로 처리한다. 실행 중인 프로세스와 append-only/완료 파일을 확인하고 중복 실행하지 않는다. 결과가 전체 상대에서도 우세하면 새 frozen teacher를 먼저 검증하고 residual PPO 또는 제어 정책 학습에 연결한다. 우세가 유지되지 않으면 기존 기준을 유지하며 기존 행동을 보존하는 정규화 학습을 검토한다.

```powershell
& '.venv-cpu\Scripts\python.exe' -X utf8 -u -m tools.league_teacher_candidate_assess --source runs/league_recent_round_robin_20261007 --out runs/league_teacher_candidate_assessment_20261007
```

아직 새 기준을 승격하지 않았고, 최종 평가·미사용 상대 평가를 열었다고 주장하지 않는다. GitHub 자동 업로드는 제외한다.
