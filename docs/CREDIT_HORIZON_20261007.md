# 새 조건 결과와 보상 연결 길이 비교

## 다섯 분기 완료 시점

긴 rollout 방식의 두 반복 승률은 68.75%, 65.63%로 평균 67.19%다. GAE 변경 방식 평균 62.50%보다는 높지만 공통 시작 정책 71.09%에는 미치지 못한다. 원시 대결·실제 설정·보존 검사는 `five_branches_partial_raw_analysis.json`을 참고한다. 마지막 `short/s6201` 실행을 마친 후 전체 결과를 확정한다.

## GAE 변경 방식의 두 반복 완료

`long_credit`의 두 반복 승률은 61.33%, 63.67%로 평균 62.50%다. 공통 시작 정책의 71.09%를 넘지 못했다. 나머지 두 방식의 두 번째 반복은 아직 진행 중이므로, 방식 간 평균 비교는 미완료다. `four_branches_partial_raw_analysis.json`에 완료된 네 분기의 원시 대결·모델/버퍼 설정·점수·정책 보존 검사를 남겼다.

완료된 학습 로그만 읽어 마지막 131,072 기록 단계 구간의 KL·clip 비율·entropy·가치 함수 지표를 `completed_training_metrics_partial.json`에 보존했다. 첫 반복의 마지막 기록 KL은 약 0.0005~0.0011로, 관측된 구간에서 큰 정책 변화 폭주는 보이지 않았다. 이것만으로 학습이 안정적으로 개선된다는 뜻은 아니다. GAE별로 학습 목표값이 달라져 value loss를 전략 성능처럼 직접 비교해서는 안 되며, SB3 로그는 마지막 학습 업데이트 직전 값일 수 있다.

## 첫 두 분기의 중간 결과

첫 `long_rollout/s6200`도 1,048,576단계를 완료했다. 승률은 68.75%로 `short`의 60.94%보다 높았지만 시작 모델의 71.09%보다 낮다. 상대 그룹 균등 승률은 75.36%로 시작 모델 74.95%보다 소폭 높았으나, 하위 상대 점수 등을 포함한 동결 평가 기준은 시작 모델보다 낮아 기존 모델을 유지했다. 두 분기 모두 이탈 상대에 0승 8패, evader에 8무승부였다. `first_two_partial_raw_analysis.json`에서 실제 모델·rollout 버퍼 설정과 원시 대결·점수·보존 결과를 검사했다. 첫 난수 반복의 일부 결과이며 전체 비교 완료를 뜻하지 않는다.

새 초기 조건 86M에서 5,600판 대결을 완료했고 종료 코드 0을 확인했다. 700개 원시 대결 파일의 요청·기록을 검사하고 전체 집계를 재계산해 `analysis.json`과 일치함을 확인했다. 입력 해시는 `runs/league_history_transfer_assessment_20261007/raw_transfer_verification.json`에 기록했다.

| 고정 정책 | 전체 승률 | 상대 그룹 균등 승률 |
|---|---:|---:|
| 최선 단일 시점 | 67.31% | 72.75% |
| 최선 시간 관측 | 60.50% | 66.07% |
| 공통 시작 정책 | 56.44% | 59.95% |
| 보존한 CEM | 49.88% | 63.33% |

단일 시점 후보가 새 조건에서도 우세했다. 다만 행동 난수와 초기 조건을 함께 재표집한 전체 승률 차이의 구간은 시간 관측 대비 -3.62~16.00%p, 공통 시작 정책 대비 -5.13~27.00%p여서 개선을 확정하기에는 불확실성이 크다. 상대 그룹 균등 점수의 시간 관측 대비 차이 구간은 +0.53~10.73%p였다. 모두 이 상대 목록과 두 행동 난수에 조건부인 결과이며, 독립 재학습이나 임의의 대회 참가자에 대한 보장은 아니다.

단일 시점 후보의 Ace 결과는 15승 1무 0패였지만, `temporal_extend_right`에는 0승 16패, `temporal_weave_right`에는 2승 6무 8패, `evader`에는 16무승부였다. 시간 관측도 이탈 상대를 해결하지 못했다. 원래 CEM은 evader에 4승 4무였다. 평균 개선이 모든 약점의 개선을 뜻하지 않는다.

후속 비교는 단일 시점 후보에서 가중치·가치 함수·Adam 상태를 복원한다. 기존 상대를 유지하고 이번 최선 단일 시점·시간 관측 정책의 두 행동 난수 버전을 각각 추가해 104상대로 만든다. 상대 가중치는 이번 후보의 승률로 갱신한다. 방식마다 같은 상대 분포와 새 초기 조건 스트림을 쓰며, 공식 물리·행동 주기·승패는 바꾸지 않는다.

| 방식 | 환경별 rollout 길이 | GAE lambda |
|---|---:|---:|
| short | 128 | 0.99 |
| long_rollout | 512 | 0.99 |
| long_credit | 512 | 0.997 |

512단계끼리의 비교는 GAE 변경의 효과를 본다. 128과 512의 비교는 업데이트 간격과 배치 수집량도 달라지므로 순수한 시간 범위 효과로 해석하지 않는다. 감마 0.999와 보상 shaping, 학습률·entropy·clip·KL·epoch·batch 설정은 유지한다. GAE가 짧아 이탈·추격 결과를 충분히 연결하지 못할 수 있다는 가설을 검증하는 것이며, 이미 원인이 확인됐다는 뜻은 아니다.

실행기 `tools/league_credit_horizon_train.py`는 로드 설정 전체를 검사하고 모델과 rollout 버퍼 양쪽에 GAE를 적용해 실제 설정을 기록한다. 먼저 세 방식 각각 32,768단계의 실제 학습·저장·복원 점검을 한다. 통과하면 방식별 두 난수 반복 × 1,048,576단계, 총 6,291,456단계를 실행한다. 학습 조건은 280M/281M, 개발 조건은 87M이다. 개발 평가로 모델을 선택하며 미사용 상대·최종 평가는 따로 남긴다. GitHub 업로드는 제외한다.

세 방식의 실제 점검은 총 98,304단계로 완료됐고 종료 코드 0을 확인했다. 모든 방식에서 가중치·Adam 저장 복원, 저장한 GAE·rollout 설정 복원, 실제 모델과 버퍼의 설정 일치를 확인했다. 원시 결과 분석기 `tools/league_credit_horizon_analysis.py`도 점검 결과를 재계산해 통과했다. 점검의 소규모 승률은 전략 비교 결과로 해석하지 않는다.

본 실행의 첫 `short/s6200` 분기가 1,048,576단계를 완료했다. 이번 개발 패널의 공통 시작 승률은 71.09%, 후속 후보는 60.94%였으며 기존 시작 모델을 유지했다. 원시 기록에서 승률과 평가 점수 일치를 확인한 기록은 `runs/league_credit_horizon_train_20261007/short_first_raw_analysis.json`에 남겼다. 새 87M 조건과 갱신한 상대 패널이므로 86M의 67.31%와 직접 전후 비교하지 않는다. 나머지 다섯 분기를 비교하기 전에는 전체 전략의 효과를 확정하지 않는다.
