# 경기별 정책 혼합의 사전 가능성 계산

## 새 조건 비교 완료

`league_mixture_screen_20261008`의 3,840경기는 종료 코드 0, `mixture_screen_raw_verified`로 완료됐다. 48개 상대 패널 승률은 혼합 53.52%, PPO7001 55.21%, PPO7000 56.38%, 출발 PPO54.17%, 교사51.82%, CEM54.43%다. 혼합의 코드 유형 균등 승률도 두 새 PPO보다 낮았다. 혼합 후보는 보존하되 교체하지 않는다.

두 구성 요소의 60/40 산술 참고값은 평균 승률52.86%·최저 상대 점수0.3125다. 실제 두 고정 행동 난수 혼합 결과와 다르며, 동일 기록의 계산상 약점 보완이 새 조건에서 PPO에 대한 전체 우위로 이어졌다는 증거는 없다. 경기별 무작위 혼합이 항상 더 낫다는 결론도 내리지 않는다.

총 실행 시간은 약418초였다. NumPy360개 묶음의 작업 시간 합은 약3,107초, 일반120개는824초였고, 일반 작업자2개 쪽이 마지막까지 남았다. 이는 다음 작업자 배분의 참고 자료이며 12+4 구성을 실제 비교 측정한 결과는 아니다. 현재 동결 실행은 바꾸지 않았다.

후속은 `league_risk_break_train_20261008`의 전술 변수 학습이다. 자기 사격 기회 중에도 상대 위협에 따라 이탈할 수 있는 별도 조건을 시험한다. 상세 설명은 `RISK_BREAK_CEM_20261008.md`를 참고한다.

## 실행 후보와 새 조건 비교

할인율 실험 완료 후 `experiments/league/episode_mixture_20261008`에 실제 제출 인터페이스를 갖춘 혼합 후보를 만들었다. 원래 두 제어기의 소스를 그대로 묶었다. 공개 첫 관측의 39개 float32 채널과 고정 행동 난수로 전용 난수를 만들고, 한 경기 동안 하나의 제어기만 사용한다. 숨겨진 환경 시드·상대 ID는 사용하지 않는다. 명시적 reset과 시계 역행 모두 새 경기로 처리한다.

총 9,600개 합성 행동에서 원본·배포 코드의 일치, 선택 유지, 극단 확률 0/1, 초기화를 검사했다. 이어 `league_episode_mixture_qualification_20261008`에서 80경기를 실행했고 종료 코드 0으로 통과했다. 일반/NumPy 실행의 공식 에피소드·요약·선택된 피해 추적이 같았으며, 극단 확률 후보의 24경기는 원래 교사/CEM 결과와 정확히 같았다. 이는 성능 향상 검증이 아니라 실행 정확성 검증이다.

`league_mixture_screen_20261008`에서는 104M의 새로운 네 초기 조건을 양쪽 자리에서 평가한다. 전체 154개 상대는 보존하되, 이전 취약 상대 12개·새 학습 후보 8개·이미 소비된 전환 상대 8개를 포함하고 각 코드 유형을 빠뜨리지 않는 패널을 선택한다. 이 부분집합의 승률을 전체 상대 승률로 부르지 않는다. 교사/CEM은 결정적 실행 한 번씩, 혼합 및 PPO는 행동 난수 두 개씩 평가한다.

비교 정책은 실제 혼합, 개발 순위로 고정한 통제 PPO7001, 다른 통제 PPO7000, 공통 출발 PPO6900, 순수 교사, CEM6800이다. 별도로 두 구성 요소 기록의 60/40 산술 가중 참고값을 보고하되 실제 혼합 실행 승률과 구분한다. 새 결과로 혼합 확률을 조정하지 않는다. 원시 기록 검증을 자동 실행하며, 이후 유망할 때 더 넓은 상대·미사용 조건에서 확인한다.

```powershell
& '.venv-cpu\Scripts\python.exe' -X utf8 -u -m tools.league_mixture_screen --source runs/league_discount_train_20261008 --out runs/league_mixture_screen_20261008
```

위 명령도 아래의 세 스레드 환경변수를 먼저 설정하고 `aircombat-rl`에서 실행한다. 이미 실행 중인 작업을 중복 시작하거나 동결된 출력·조건 예약을 덮어쓰지 않는다. GitHub 업로드는 제외한다.

## 아래는 실제 후보 생성 전 가능성 계산 기록

할인율 PPO 실험은 그대로 진행하면서, 이미 완료된 102M 대결 행렬만으로 다른 후속 방법을 계산했다. 새 비행 시뮬레이션이나 정책 배포는 하지 않았다.

다섯 후보는 PPO6900·PPO6901·출발 PPO·순수 extend-right·CEM6800이다. 경기 시작 때 하나를 확률적으로 선택해 끝까지 사용하는 혼합을 가정한다. 각 확률을 5% 간격으로 나눈 10,626개 조합에서, 평균 승률이 출발 PPO 이상인 조합 중 가장 낮은 상대별 기대 점수(승리 1·무승부 0.5·패배 0)를 최대화했다. 전역 최적해를 구한 것이 아니라 유한 격자 탐색이다.

그 기록에서는 **순수 교사 60% + CEM6800 40%**가 선택됐다. 예상 평균 승률은 80.07%, 최저 상대 기대 점수는 0.3625다. 개별 정책의 최저 기대 점수는 PPO6900 0.25, PPO6901 0.28125, 출발 PPO 0.21875, 교사 0.125, CEM 0.25다. 행동 난수를 평균한 기대 점수이므로 기존 보고서의 행동 난수별 보수적 최솟값과 직접 혼동하지 않는다.

이 값은 **가중치를 맞춘 동일 기록에서 계산한 값**이다. 과적합과 표본 오차가 있으며 개선을 입증한 결과가 아니다. 공식 판정은 바꾸지 않고, 무승부 0.5는 계산용 평가 관례다. 혼합이 신경망 학습 성과인 것도 아니다. 실제 제출 가능한 정책은 아직 만들지 않았다.

재현 결과는 `runs/mixture_feasibility_reproduced_20261008.json`이며, 입력 원시 기록과 분석 코드 해시를 포함한다. 최초 계산은 `runs/mixture_feasibility_20261008.json`에 보존했다. SciPy는 설치돼 있지 않아 추가 설치 없이 NumPy 격자로 계산했다.

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
& '.venv-cpu\Scripts\python.exe' -X utf8 -m tools.league_mixture_feasibility --source runs/league_expanded_ppo_assess_20261008 --out runs/mixture_feasibility_new_output.json
```

할인율 실험 후 결과를 함께 보고 실제 혼합 후보를 채택할지 결정한다. 채택 시 경기 시작의 선택·초기화·공식 행동 출력을 검증하고, 가중치를 고정한 후 미사용 초기 조건과 상대에서 확인해야 한다. 새 결과로 가중치를 다시 맞추면 그 결과는 미사용 평가가 아니다. 기존 학습 모델과 모든 CEM 정책을 보존한다.
