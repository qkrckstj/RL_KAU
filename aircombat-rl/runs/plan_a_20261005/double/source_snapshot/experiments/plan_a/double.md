# Double DQN 자동 연장 — 2026-10-05

FairFight, 31개 단일시점 관측, 종료 보상, lr=0.001, gamma=0.999,
기존 네트워크·탐험·버퍼·target 갱신 주기를 유지한다. 온라인 네트워크로
다음 행동을 선택하고 타깃 네트워크로 그 행동의 값을 평가하는 변경만 적용한다.

시드 0·1·2를 새로 학습한다. 각 1,024,000스텝을 먼저 수행하고,
각 시드의 마지막 검증 승리가 양수이며 최근 5회 중 3회 이상 승리가 있고,
최근 5회 승리 합이 직전 5회보다 낮지 않으면 2,048,000까지 연장한다.
같은 기준을 통과하면 4,096,000까지 연장한다. 최대 총 12,288,000스텝이다.
조건 미충족 시 해당 시드는 종료하고 최고 모델을 보존한다.
동일 프로세스·learner·replay·시뮬레이터를 유지하며 연장 시 epsilon=0.05를 유지한다.

검증은 band 900000, 양 좌석 20경기, 간격 51200이다.
매 검증 가중치·Q 표본 진단을 저장하고 단계 종료 시 replay/RNG를 저장한다.
시드별 실제 최종 스텝은 result.json, 연장 결정은 extension_decisions.json에 남긴다.

전 시드 종료 후 100만 예산 및 각 실제 최종 예산의 검증 최고/마지막 모델을 고정한다.
기존 노트북 학습률 실험의 lr=0.001 대조군을 가중치·검증 이력 해시와 함께 재사용한다.
새 시험 band 1500000, 양 좌석 40경기를 모든 선택 완료 후 한 번 평가한다.
동일 예산 비교와 서로 다른 예산의 연장 결과를 구분하며, 시험 승률로 재선택하지 않는다.
대표 모델은 기존 규칙(검증 승리→승리 시간→이른 스텝→낮은 시드)으로 시험 전에 고정한다.
