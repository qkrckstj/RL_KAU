# 재생 버퍼 5만 / 50만 비교

같은 Double DQN 시드 1 체크포인트에서 이어 학습한 탐색적 비교다. 시작/검증 최고/마지막 모델을 같은 새 시험에서 평가했다.

| 버퍼 크기 | 모델 | 스텝 | 시험 승리 |
|---:|---|---:|---:|
| 50000 | starting | 1024000 | 2/2 |
| 50000 | validation_selected | 1024000 | 2/2 |
| 50000 | final | 1024128 | 0/2 |
| 500000 | starting | 1024000 | 2/2 |
| 500000 | validation_selected | 1024000 | 2/2 |
| 500000 | final | 1024128 | 0/2 |

검증 이력의 replay_diagnostics에 양의 보상 경험 수·Q값 이탈·버퍼 크기를 기록했다.
학습 재개용 replay/RNG는 시작과 마지막 체크포인트에 보관했다. 중간에는 가중치만 저장했다.
