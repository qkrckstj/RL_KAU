# Plan A — FairFight 기본 정책 비교

실행일: 2026-10-01. 이 문서는 결과를 보기 전에 정한 실험 조건과 해석 범위를 기록한다.

## 범위

원본 기준 모델 재현 → 관측 개선 → 같은 환경에서 DQN/PPO 비교를 수행한다.
공식 JSBSim 모델, 자동조종기, 상대 정책, 행동 공간, 경기·채점 규칙은 변경하지 않는다.
이 단계에서는 중간 보상, 자기 대전, 전이 학습, 연속 행동을 추가하지 않는다.

## 원본 재현 A0

저장소의 `templates/project_04_fair/train.py`와 `baseline/`을 사용했다.
CPU 1스레드, seed 0, 200,000스텝, 원래의 25,000스텝 검증 간격과 30개 검증 에피소드,
원래의 할인율 0.99·시간 제한 처리를 유지했다. 결과는
`runs/plan_a_20261001/a0_original/baseline/s0/`에 저장한다.

원본 재현은 실행 기준점이다. 아래 실험과 검증 좌석·학습 스케줄·할인율·종료 처리가
다르므로 성능 차이를 관측 개선 하나의 효과라고 해석하지 않는다.

## 통제된 비교

| 이름 | 알고리즘 | 관측 | 비교 목적 |
|---|---|---|---|
| `control_dqn` | DQN | 원본과 같은 거리·자신의 체력 2개 | 공통 학습 설정에서의 기준 |
| `observed_dqn` | DQN | 상대 관계와 기체 상태 31개 | 같은 DQN에서 관측 변경 효과 |
| `observed_ppo` | PPO | 같은 31개 | 같은 관측에서 알고리즘 변경 효과 |

공통 조건:

- FairFight, 이산 행동 9개, 훈련 좌석 red, 공식 평가에서는 red·blue 모두 사용.
- seed 0·1·2의 독립 학습 3회, 실행당 **204,800스텝**. PPO rollout 1,024의 정수배로 맞췄다.
- CPU, PyTorch 1스레드. 최대 3개의 독립 실행을 동시에 수행하므로 기록된 벽시계 시간은 전용 장치 속도 벤치마크가 아니다.
- 할인율 `gamma=0.999`. 20 Hz에서 120초 후 보상의 할인계수는 약 0.0906이다.
- 원래 종료 보상 유지: 승리 +1, 그 외 종료 -0.2, 진행 중 0.
- 실제 경기 시간 종료는 학습 래퍼에서 terminal로 처리한다. 일반적인 외부 수집 중단은 truncation으로 유지한다.
- 모델 입력은 공개된 39개 관측에서만 계산한다. `info`의 추가 기하 정보나 상대의 내부 명령을 정책에 제공하지 않는다.
- 숨은 층 폭은 64·64, ReLU. DQN의 Q망과 PPO의 actor/critic 구조·파라미터 수는 다르므로 동일 파라미터 수 비교는 아니다.

원본의 시간 종료 표시는 `truncated=True`이지만 시간 종료 자체가 최종 결과와 패배 보상을
결정한다. 이번 비교에서는 유한한 경기 목표로 해석해 bootstrap을 끊는다. 관측이 2개인
기준 모델에는 남은 시간이 없고, 31개 모델에는 포함된다. 이 부분도 관측 변경의 일부다.

### 알고리즘 설정

DQN: 학습률 0.001, replay 50,000, 학습 시작 1,000스텝, batch 32,
4스텝당 1회 갱신, target 갱신 1,000스텝, epsilon 1.0→0.05를 전체 예산 앞 10%에서 감소.

PPO: 학습률 0.0003, rollout 1,024, batch 64, epoch 10, GAE lambda 0.95,
clip 0.2, entropy 계수 0.01, target KL 0.03. KL 조건에 따라 실제 epoch 수는 줄어들 수 있다.

두 알고리즘 모두 `learn()`을 전체 예산에 대해 한 번 호출한다. 원본처럼 반복 호출할 때
발생하는 탐험 스케줄의 재계산을 피한다. 환경 상호작용 수는 같지만 gradient 갱신 횟수를
같게 맞추지는 않는다. 이것은 고정된 후보 설정의 초기 비교이며 최적 튜닝 후 우열의 증명은 아니다.

### 31개 관측

거리, 자신의 기수 기준 상대 위치, 상대 방위의 sin/cos, 양측 기수 차이의 sin/cos,
상대 거리 변화율·횡방향 속도, 양측 속도·롤·요 각속도·하중·체력·추적 시간·유효 조건 여부·
경계까지 거리, 남은 시간, 고도 차이, 양측 수직 속도를 사용한다.

고정된 물리 스케일과 tanh/sin/cos 변환을 사용해 대체로 [-1,1] 범위로 제한한다.
학습한 정규화 통계나 미래 정보는 사용하지 않는다. 전체 순서와 스케일은 `core.py`와
각 실행의 `config.json`에 저장한다. 모델에 넣는 고도 차이·수직 속도는 고도 유지 제어의
잔여 운동을 나타내며, 정책에 고도 변경 행동을 추가한 것은 아니다.

추가한 [FAA Airplane Flying Handbook Chapter 4](<../../../학습 관련 논문/05_afh_ch4.pdf>)의
pp. 4-1~4-3에서 설명하는 에너지·속도 관계를 관측 검토에 참고했다.
이 교범은 전투 교리가 아닌 일반 비행 교범이다. 이번 실험에서는 속도 관련 정보를
관측에 포함했으며, 교범만으로 특정 속도나 기동을 정답으로 정하거나 보상에 강제하지 않았다.

## 검증과 최종 시험

- 학습 시작 전 검증은 미학습 상태의 참고값으로만 기록하고 체크포인트 후보에 넣지 않는다.
- 51,200스텝마다 검증한다. seed 900,000부터 10개 초기 조건을 양쪽 좌석에서 평가해 총 20경기다.
- 검증 승리 수가 큰 모델을 선택하고, 동률이면 평균 승리 시간이 짧은 모델을 선택한다.
  완전 동률이면 먼저 저장한 학습 체크포인트를 유지한다.
- 모든 모델의 훈련과 설정 선택이 끝난 뒤, 별도 seed 1,100,000부터 양쪽 20경기씩 총 40경기를 평가한다.
- 최종 시험에는 `tools.grade.score()`를 사용한다. 시험 seed는 이번 비교에서 보류한 집합이며,
  교수자의 숨겨진 채점 seed와 같다는 뜻은 아니다.
- 승률뿐 아니라 사망·상호 종료·시간 초과, 양측 체력, 추적 시간, 좌석별 결과를 보존한다.
- 3회 학습은 선별용 반복 수다. 40경기를 여러 번 평가한 것을 독립 학습 수와 혼동하지 않는다.
  차이가 작거나 반복 간 일관성이 없으면 우위 미확인으로 보고한다.

## 검증한 구현 조건

새 테스트는 원본 관측과 기준 모델의 일치, 좌표 회전·이동에 대한 상대 관측의 일관성,
양쪽 좌석의 유한하고 제한된 관측, 학습·추론 전처리의 일치, 실제 경기 종료와 외부
중단의 구분을 확인한다. 짧은 실행은 세 모델의 학습·저장·공식 평가기 재로딩을 확인한다.

각 실행 폴더에는 독립적으로 평가 가능한 `policy.py`, `wrappers.py`, `utils.py`,
`policy_net.zip`을 함께 저장한다. `utils.py`는 실행 당시 `core.py`의 복사본이며,
관측·설정 변경 후 과거 모델이 다른 전처리로 평가되는 것을 방지한다.

## 실행 명령

저장소 루트의 PowerShell에서:

```powershell
.\.venv\Scripts\python.exe -m tools.plan_a matrix --out runs\plan_a_20261001\comparison --workers 3
.\.venv\Scripts\python.exe -m tools.plan_a test --out runs\plan_a_20261001\comparison
```

두 번째 명령은 첫 번째가 모두 끝난 뒤 실행한다. 같은 출력 경로에서 완료된 실행은
건너뛰며, 미완료 실행은 처음부터 다시 학습한다. optimizer·replay까지 이어지는 중간 재개는
구현하지 않았다. 다른 설정을 비교할 때는 새로운 출력 폴더를 사용한다.

실험 결과는 `runs/plan_a_20261001/` 아래에 저장되며 Git에서는 제외된다.
