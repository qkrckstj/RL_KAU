# A4 독립 학습 seed 확인 — 조건부 사전 프로토콜

작성일: 2026-10-01. A3 최종 시험을 열기 전에 후속 실행 규칙을 정한다.

A3의 사전 기준(선택 모델 평균 시험 승률 +10%p 이상, 3개 중 2개 이상 개선,
끝 모델 평균 성능 비악화)을 통과한 경우에만 실행한다. 통과하지 못하면
검증·replay 진단으로 진행한다.

- 새 학습 seed 3·4·5. A3 seed 0·1·2와 분리한다.
- 두 보상 terminal / potential_v1을 각각 1,024,000스텝 새로 학습한다.
- A3와 동일한 알고리즘·관측·행동·보상 계수·gamma·탐험 일정·검증 절차.
- CPU 1스레드씩 실행한다. CUDA로 장치를 중간 변경하지 않는다.
- 검증 band 900000, 매 51200스텝 20경기.
- 이번 확인의 주 예산은 1024000 하나다. 모든 중간 가중치를 저장하고,
  검증 선택 모델 및 마지막 모델을 별도로 평가한다.
- 학습과 검증 기반 선택이 모두 끝난 뒤 **새 시험 band 1400000**, 양 좌석 40경기를 평가한다.
- 독립 확인에서도 A3와 같은 차이 기준을 확인한다.
- A3와 A4는 서로 다른 시험 초기조건을 쓰므로 단순히 240경기를 독립 학습처럼 합치지 않는다.
  단계별로 대응된 학습 seed의 차이를 보고한다.
- 최종 대표는 각 단계의 시험 전에 검증으로 고른 정책이며 시험 점수로 다시 고르지 않는다.
- 이 고정된 확인 실험 이후에는 결과·재현 자료를 정리하고 추가 학습을 종료한다.
  확인 실패 시에도 새 시험을 보면서 potential 계수나 탐험 일정을 바꾸지 않는다.
