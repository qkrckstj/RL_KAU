# 학습률 안정성 비교 — 2026-10-05

FairFight, 31개 단일시점 관측, DQN 64·64, 종료 보상을 고정한다.
같은 노트북 CPU에서 학습률 0.001 / 0.0001 각각 seed 0·1·2를
1,024,000스텝 새로 학습한다. 총 6,144,000스텝이며 이전 버퍼를 사용하지 않는다.
그 외 gamma 0.999, replay 50000, batch 32, 4스텝당 1회 갱신,
target interval 1000, 최초 20480스텝 epsilon 1→0.05를 유지한다.

51200스텝마다 기존 검증 band 900000에서 양 좌석 총 20경기를 평가한다.
204800/512000/1024000 예산 내 최고 모델과 각 예산 마지막 모델을 구분한다.
모든 중간 가중치와 예산별 replay/RNG를 저장한다.
검증 시 고정된 별도 RNG 표본으로 Q 범위 이탈을 기록해 학습 RNG에 영향을 주지 않는다.

모든 학습 완료 후 검증 승리 수→승리 시간→이른 체크포인트로 선택을 고정한다.
조건별 검증 선택 모델의 총 검증 승리 수→승리 시간으로 조건을 고르고,
완전 동점은 기존 학습률을 유지한다. 시험 전에 대표 모델의 해시를 저장한다.
새 시험 band 1400000에서 각 모델 양 좌석 40경기를 평가한다.
시험 점수로 대표 모델을 재선택하거나 설정을 수정하지 않는다.

최고 모델뿐 아니라 마지막 모델 승률, 마지막 5개 검증 성적, Q값 이탈을 보고한다.
추가 학습 검토 조건은 최소 2개 시드의 마지막 검증 승리가 0보다 크고,
최근 5개 검증의 전체 평균이 직전 5개보다 낮지 않은 경우다.
조건 충족만으로 자동 연장하지 않으며 별도 예산·시험 계획을 먼저 고정한다.
충족하지 않으면 기존 최고 모델을 보존하고 이번 학습을 종료한다.

실행: `python -m tools.plan_a_stability run --out runs/plan_a_20261005/stability --workers 3`
설치 검증용 smoke는 기존 검증 band만 사용하며 본 학습과 출력 폴더를 분리한다.
선택기 재사용에 따른 JSON의 `reward` 필드는 이 실험에서는 학습률 조건 이름이다.
실제 학습 보상은 두 조건 모두 terminal이며 config.json의 spec으로 확인한다.
