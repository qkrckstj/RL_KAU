# 자동 반복 실험 기록

**2026-10-06 완료.** 최종 배포 정책200/200승, 기준69/200승으로 성공 기준을 충족했다.
핵심 결과와 실행 파일은 [완료 보고서](autolab_result.md)에 정리했다. 아래는 순서대로 남긴 실험 기록이다.

사용자가 2026-10-05 자동 학습→분석→다음 실행의 반복을 명시적으로 요청했다.
현재 목표/성공 기준은 저장소 루트 `AUTOLAB.md`에 있다. 미사용 최종 시험 band2000000은 아직 열지 않았다.

## 1. 탐험 노이즈 진단 — 주원인 가설 보류

훈련 없이 좋은 DDQN 정책의 행동에 epsilon 0/.005/.05를 주입했다.
동일 검증900000의20경기에서 각각9/11/10승이었다.
고정 좌선회는8/10/9승이었다. 해당 범위의 무작위 조작이 붕괴의 주원인이라는 근거가 없어
탐험률만 변경하는 추가 훈련을 생략했다. 20경기이므로 작은 차이의 우열은 주장하지 않는다.

## 2. 좋은 행동으로 초기화한 PPO — 이 설정의 확대는 기각

DDQN seed1/1024000의 actor층을 복사하고 출력 크기를 훈련 replay만으로 정했다.
훈련 replay4096개에서 greedy 행동100% 일치를 확인했다. critic은 새로 학습했다.
131072스텝씩3회, 같은 사전학습 모델을 공유한 독립 미세조정이다.
gamma.999, GAE1, lr.0001, rollout2048, batch256, epochs5, entropy0, KL목표.01이었다.

검증902000,10초기조건×양 좌석:

| 미세조정 seed | 시작 | 최고 | 최종 | 학습 중 승리/경기 |
|---|---:|---:|---:|---:|
|700|7/20|8/20|4/20|36/84|
|701|7/20|7/20|5/20|32/81|
|702|7/20|8/20|7/20|28/79|
|고정 좌선회·감속|7/20|—|—|—|

최고 평균38.3%, 최종26.7%, 고정35%다. 후반 성능 유지 문제를 해결하지 못했다.
학습 중 성공 경험은 있었으므로 이번 실패를 단순히 성공 경험이 없었기 때문이라고 설명할 수 없다.
출력을 크게 확대하여 복사한 actor는 엔트로피가 낮았고 critic 설명력도 불안정했다.
이는 가능한 후속 진단 항목이며 이번 비교만으로 인과 관계를 확정하지 않는다.
세부 데이터: `runs/autolab_20261005/ppo_pilot/`.

## 3. CEM 직접 정책 탐색 — 첫 탐색 완료, 독립 재현 실행 중

좋은 정책들이 단순 선회와 비슷했으므로, 7개 제어 파라미터를 실제 경기 승패로 학습한다.
초기 좌선회에서 기하학적 추적으로 전환하는 제한된 정책 계열이다.
완전한 신경망 정책 또는 일반적인 교전 지능을 확보한 것으로 표현하지 않는다.

seed800/801/802, 각각12후보×6세대×6훈련 경기. 매세대 훈련 초기조건을 교체하며
같은 세대의 모든 후보는 같은 조건에서 비교한다. 개발 검증903000의20경기는 세대 선택에만 쓴다.
고정 좌선회를 동일 검증 조건으로 재측정한다. 새 최종 시험은 열지 않는다.

`tools/autolab_cem.py`가 학습·검증·기록을 실행하며 각 후보의 원시 경기 기록과
탐색 분포/RNG를 세대마다 저장한다. `policy.py`와 `policy_net.json`으로 내보내고,
공식 grader에는 `--policy <파일>`을 명시한다. 테스트3개 및 실제 환경 smoke를 통과했다.
세부 데이터: `runs/autolab_20261005/cem_pilot/`.

첫 탐색 최종 결과(개발 검증903000, 각20경기):

| 탐색 seed | 최고 | 최종 | 실제 훈련 스텝 |
|---|---:|---:|---:|
|800|20/20|20/20|695356|
|801|19/20|19/20|719876|
|802|18/20|18/20|747433|
|고정 좌선회·감속|7/20|7/20|—|

평균95% 대 기준35%이고 세 탐색 모두 최고 성능을 마지막에 유지했다.
이는 개발 검증 결과이며 최종 일반화 성능으로 주장하지 않는다.
시행된 학습량은1296경기/2162665스텝이다. 각 경기 중 네트워크 갱신을 하는 DQN과
학습 구조/표현이 달라, 이 결과를 동일 모델의 알고리즘 하나만 바꾼 비교로 해석하지 않는다.

2026-10-05 23:54 KST에 후속 스크립트가 문턱 통과를 확인하고 재현을 자동 시작했다.
seed803/804/805, 같은 탐색 설정, 새 훈련 초기조건4000000부터, 개발검증904000의40경기를 사용한다.
재현이 통과하면 선택을 고정하고 최종 시험2000000의200경기로 넘어간다.
시험을 보기 전에 고정한 미학습 기본 제어기2종도 추가 비교하여 구조 변경과 학습 효과를 구분한다.
코드: `tools/autolab_cem_followup.py`, `tools/autolab_cem_controls.py`.

최종 배포할 단일 정책은 재현3개의 **개발 검증 승리 수**, 동률이면 체력차,
완전 동률이면 작은 탐색 seed 순으로 고른다. 최종 시험 성적으로 배포 모델을 고르지 않는다.

## 4. 초기 탐색의 재현 관문 실패와 교차 확인

새 탐색803/804/805의 최고는17/23/28승/40경기, 최종16/18/28승이었다.
평균 최고56.7%, 최종51.7%, 같은 조건의 고정 기준42.5%였다.
성공 관문을 넘지 못하여 시험을 열지 않고 중단 원인을 분석했다. 자동 목표 자체는 계속된다.

두 개발 조건을 교차 평가했다:

|---|---:|---:|
|800|20|38|
|801|19|37|
|802|18|22|
|803|16|17|
|804|7|23|
|805|12|28|

800/801은 조건이 달라져도 강했으므로 모든 부진을 새 조건의 난이도로만 설명할 수 없다.
동시에802/803은 조건에 민감했다. 최초 세대의803은12후보가 모두0승/6경기여서
승패로 후보를 구분하지 못했고, 여러 세대에서도 동일 승리 수가 많았다.
표본 부족 및 탐색 분포의 초기 경로 의존성을 후속 가설로 삼는다. 단일 인과 원인 확정은 아니다.
