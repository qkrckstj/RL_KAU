# 시간에 따라 행동을 바꾸는 미학습 상대

현재 `league_conditions_20261006` 학습에 포함하지 않은 상대다. 경기 결과를 보기 전에 코드·설정·모델 해시를 `../temporal_panel_20261006.json`에 동결했다.

| 동작 | 내용 |
|---|---|
| weave | 가까운 상대가 자신을 향하면 일정 주기로 회피 방향 반전 |
| extend | 일정 시간 이탈 후 추격 복귀; 재발동 대기 시간 포함 |
| delayed | 초기 자기 기수 기준 기동 후 추격 |
| pulsed | 추격 목표 방향에 시간에 따른 진동 적용 |

각 동작에 방향 -1·주기/유지시간 4초·목표 속도 400kt, 방향 +1·8초·600kt의 두 설정이 있다. 방향 하나의 효과를 비교하는 실험은 아니다. 여덟 상대는 네 동작의 변형이며 실제 학생 정책·전문가 조종·독립 구조 8개를 뜻하지 않는다.

공식 39개 관측값만 사용해 9개 이산 행동을 반환하고 경기마다 기억을 초기화한다. 상대 ID·비공개 상태는 읽지 않는다. 공식 비행 물리·초기조건·무장·승패 판정은 유지한다.

`tools.league_temporal_audit_v2`가 학습 종료까지 작업자 없이 기다린다. 현재 실험의 최종 검증이 `evaluation_passed`인 경우에만 원래 CEM·현재 검증 모델·선택된 새 모델을 band 52000000에서 비교한다. 상대당 40초기조건 × 양 좌석, 모델당 640경기, 전체 1,920경기다. 실패 시 `not_eligible`을 기록하고 평가를 열지 않는다. 실제 상태는 `runs/league_temporal_audit_v2_20261006`과 프로세스 명령줄을 함께 확인하며 살아 있는 제어기를 중복 실행하지 않는다. 첫 대기 프로그램은 상태 파일의 Windows 접근 오류로 종료돼 기록을 보존했다. v2는 같은 대기 상태를 반복 기록하지 않고 짧은 파일 잠금을 제한적으로 재시도한다. 이 복구 동작 검사 3개도 통과했다.

후보는 평가 전에 선택되어야 하며 이 결과로 다시 고르지 않는다. 초기조건별로 묶은 승률 차이 불확실성과 모든 상대별 결과를 보고한다. 평가 완료 자체가 개선 판정은 아니다. 사용 후에는 이 상대들을 후속 학습에서 다시 미학습 상대라고 부를 수 없다.

초기화·공식 로더·조건부 실행 검사 8개와 실제 저장 상대의 합성 관측 1,600회 행동 일치를 확인했다. 실제 경기 성능·비행 완료의 증거는 아직 없다. 재실행에는 현재 코드·동결 계획·입력·모델 파일이 필요하며 이전 `replay_snapshot_20261006.zip`에는 이번 새 파일들이 포함되지 않았다. GitHub 자동 업로드는 하지 않는다.
