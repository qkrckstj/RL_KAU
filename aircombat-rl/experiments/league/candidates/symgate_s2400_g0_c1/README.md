# 검증 중인 선택기 후보

이 폴더는 `symgate_s2400_g0_c1`의 이동 가능한 추론용 사본이다. **별도 개발 선발은 통과했으나, 최종 평가에서 Evader 개선의 신뢰구간 기준에 미달했다. 기존 챔피언을 대체하는 묶음이 아니다.**

최종 1,600경기에서 기존 정책은 1,146승 320무 134패, 후보는 1,230승 236무 134패다. Circler 0→80/80승, Evader 0→4/80승이고 다른 상대의 승률은 동일하다. 전체 승률 차이의 초기조건 묶음 부트스트랩 95% 구간은 +5.0~+5.5625%p지만, Evader 차이는 0~+11.25%p로 하한이 엄격하게 양수여야 한다는 사전 기준을 통과하지 못했다. 전체 개선과 Evader 개선의 증거 부족을 구분한다. 이 실패 기록을 유지하며, 미관측 상대 감사는 실행 자격이 없어 해당 상대 패널을 열지 않는다.

공개 관측으로 0.5초 동안 상대의 회전·방위 변화를 보고, 기존 `refine_2200`과 빠른 추격기 중 하나를 선택한다. 계수는 설계 초기값 그대로다. 세 번의 CEM 검색이 모두 이를 선택했으며, 추가 학습이 새 계수를 발견한 결과로 해석하지 않는다.

`policy.py`, `wrappers.py`, `policy_net.zip`을 함께 복사하면 기존 공식 로더에서 불러올 수 있다. 정책 자체는 NumPy를 사용하며 다른 실험 폴더를 가져오지 않는다. 시뮬레이터 실행에는 프로젝트 환경과 JSBSim 등이 별도로 필요하다. 저장소 루트의 `REPRODUCE.md`를 따른다.

`aircombat-rl` 폴더에서:

```powershell
python -m tools.watch templates/project_04_fair --design experiments/league/candidates/symgate_s2400_g0_c1 --seed 123
```

이 명령은 Ace 상대 관전이다. `--seed`는 초기조건 자체가 아니라 여러 대결의 난수열을 고정한다. Space는 일시정지, Backspace는 새 대결, Esc는 종료다.

`evidence/frozen_selection.json`은 최종 시험 전에 고정한 선택과 별도 선발 성능을 보존한다. 같은 800경기에서 기존 정책 583승, 후보 627승이다. Circler 0→40/40승, Evader 0→4/40승이며 다른 18개 상대의 승률 변화는 없다. 실제 다른 학생들의 정책에 대한 결과가 아니다.

`manifest.json`은 모델·증거 파일 해시를, `evidence/packaging_check.json`은 원본과 사본의 바이트 일치 및 공식 로더의 160개 합성 관측 행동 비교를 기록한다. 이 검사는 실전 성능 평가가 아니다. 이 사본은 추론용이며 학습 재현에는 저장소의 소스와 원래 실행 기록도 필요하다.
