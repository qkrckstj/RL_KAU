# 요격 학습 모델 intercept_s2500_g3_c6

공식 FairFight에서 기존 refine_2200의 기동 정책과 관측 기반 선택기를 고정하고, 요격기 7계수를 CEM으로 학습한 정책이다. 신경망 PPO/DQN 모델은 아니다. `policy.py`, `wrappers.py`, `policy_net.zip`은 공식 정책 로더로 불러올 수 있다.

새 조건에서 시험 전에 선택된 모델이다. band 44000000, 21상대 × 80초기조건 × 양 좌석, 모델당 3,360경기에서 기존 refine_2200은 2,402승, 이전 대칭 선택기는 2,571승, 이 모델은 2,628승이었다. 기존 부모 대비 승률 차이는 +6.73%p, 초기조건 단위 paired bootstrap 95% 구간은 +6.25~+7.20%p다. 이전 대칭 선택기 대비 +1.70%p다.

Evader는 67승 93무 0패, Circler와 Ace는 각각 160승이었다. 이전 대칭 선택기의 Evader는 10승으로, 해당 상대 개선도 사전 기준을 통과했다. 다른 19상대의 승수는 기존 부모와 같았다. Ace에서 초반 피격을 줄였다는 의미는 아니다.

별도 band 42000000의 8개 미학습 계수 변형 상대에서는 기존 부모와 이 모델 모두 452승/640경기였다. 이 상대들은 이제 관측한 상대이며 후속 학습에 사용할 수 있지만 다시 미관측 성능의 근거로 삼지 않는다. 실제 수강생 정책이나 모든 전술에 대한 우위를 증명한 결과가 아니다.

원본 실행은 `runs/league_interception_train_20261006`, 기존 정책 묶음은 `experiments/league/bundle`에 보존된다. 이 폴더의 `evidence`에는 선발·최종 시험·별도 상대 평가 기록이 있고 `manifest.json`에는 파일 해시가 있다. GitHub에는 아직 업로드하지 않았다.
