# 기존 CEM을 공략하는 첫 후보

자동 리그의 두 번째 라운드에서 학습한 17개 파라미터 반응형 제어 정책이다.
신경망 가중치가 아니며, 기본 로더를 위해 JSON 계수를 ZIP으로 저장했다.
**개발 평가용 후보이며 대회용 챔피언으로 채택하지 않았다.**

같은 10개 초기 seed를 양 진영에서 평가한 상대별 20경기 결과:

| 상대 | 승 | 무 | 패 |
|---|---:|---:|---:|
| 기존 CEM |17|0|3|
| 기존 DDQN seed 1 |19|1|0|
| Ace |0|0|20|
| Pursuit |0|0|20|
| Evader |0|20|0|
| 고정 좌선회 |19|1|0|
| 고정 우선회 |15|4|1|
| 첫 라운드 후보 |15|0|5|

기존 CEM을 이긴다는 사실만으로 여러 상대에게 강하다고 판단할 수 없는 사례다.
이 후보는 다음 라운드의 훈련 상대에 포함한다. 결과와 출처는 `development_results.json`에 있다.

공식 시청 도구로 Ace와의 경기를 확인하려면 프로젝트 루트에서:

```powershell
python -m tools.watch templates/project_04_fair --design experiments/league/counter_v1 --seed 31000100
```
