# 정지 시점 실험 기록·모델 묶음

코드와 최신 보고서는 저장소에서 바로 읽을 수 있다. `manifest.json`은 원래 파일 경로·크기·SHA256과 저장 위치를 기록한다. 나머지 원시 기록·체크포인트·동결 소스는 `experiments.zip.partNNN`에 들어 있다. 각 조각은40MiB이하다. 중복 파일 내용은 한 번만 저장한다.

저장소 루트에서 Python3.12로 실행한다.

```powershell
python scripts/restore_experiment_archive.py
python scripts/restore_experiment_archive.py --verify-only
```

표준 라이브러리만 사용한다. 파일이 없으면 복원하고, 이미 같은 파일이 있으면 건너뛴다. 기존 파일 내용이 다르면 덮어쓰지 않고 중단한다. 복원 중 임시 압축파일 공간과 원래 기록을 펼칠 공간이 필요하다. **학습·평가는 시작하지 않는다.** 파일 검증 뒤 실제 모델을 실행하려면 `REPRODUCE.md`의 패키지를 설치한다.

포함: 실제 리그 실험의 원시 기록·모든 저장 체크포인트·학습 명세·동결 소스 사본·진단 상태 표본 및 명세에서 참조한 과거 입력. 제외: 가상환경·캐시·중복 복원 테스트 체크아웃·이전 복원 묶음의 중복 사본. 최신 실험에서 참조하지 않는 일부 옛 DQN replay buffer와 녹화는 로컬에 남는다. 구체적인 복원 대상은 manifest를 기준으로 한다.

현재는 사용자 요청으로 정지했다. 새 실행을 자동으로 시작하지 말고 [세 모델 선택과 중단 안내](../../docs/MODEL_CHOICE_AND_PAUSE_20261008.md)를 따른다. 과거 runtime의 PID·시간·절대 경로는 이 PC의 현재 상태를 뜻하지 않는다. 공식 FairFight와 원래 CEM은 보존했다. 다음 GitHub 업로드도 사용자가 명시적으로 요청할 때만 한다.

검증 범위는 `docs/verification/publication_20261008.json`에 기록한다. 전체 압축 내용의 해시와 별도 경로에 복원한 세 모델의 추론을 확인하며, 모든 학습·대결을 다른 컴퓨터에서 다시 실행했다고 주장하지 않는다.
